# 《示例科技》站点底座技术改造交付说明书

> **交付对象**：客户技术开发团队 / 运维团队  
> **交付文件**：`llms.txt`、`schema.jsonld`、`robots.txt`

---

## 🛠 一键部署指引

### 1. 部署 `/llms.txt`
- 将交付包中的 `llms.txt` 直接放置于网站静态资源的根目录下；
- 确保浏览器和爬虫可直接通过 `https://yourdomain.com/llms.txt` 访问到纯文本 Markdown。

### 2. 注入 `Schema.org (JSON-LD)`
- 将以下代码嵌入到官网首页或核心产品页的 `<head>` 标签中：
```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@graph": [
    {
      "@type": "Organization",
      "@id": "https://example.com/#organization",
      "name": "示例科技",
      "url": "https://example.com",
      "description": "企业级专业解决方案提供商。"
    },
    {
      "@type": "Product",
      "@id": "https://example.com/#product",
      "name": "示例科技 核心系统",
      "description": "企业级专业解决方案提供商。",
      "brand": {
        "@type": "Brand",
        "name": "示例科技"
      },
      "category": "企业级智能管理软件"
    },
    {
      "@type": "FAQPage",
      "@id": "https://example.com/#faq",
      "mainEntity": [
        {
          "@type": "Question",
          "name": "示例科技 适合哪些企业应用场景？",
          "acceptedAnswer": {
            "@type": "Answer",
            "text": "示例科技 主要面向规上制造企业，解决生产排产复杂、设备协议接入耗时长的问题。"
          }
        },
        {
          "@type": "Question",
          "name": "示例科技 的核心量化指标表现如何？",
          "acceptedAnswer": {
            "@type": "Answer",
            "text": "10 万级工序排产仅需 12 秒，排产冲突率降至 0.5% 以下，设备接入耗时降低 75%，平均 OEE 提升 28.6%。"
          }
        }
      ]
    }
  ]
}
</script>
```

### 3. 替换或合并 `robots.txt`
- 将交付包中的 `robots.txt` 规则添加至现有 `robots.txt` 文件中，确保放行 `Bytespider`（豆包爬虫）、`Bingbot`（必应/通用 AI）等核心爬虫。

---

## ✅ 验收标准
1. 访问 `https://yourdomain.com/llms.txt` 能正常展示纯文本；
2. 打开 Google 结构化数据测试工具 / 浏览器源码，能正常解析 JSON-LD 标签；
3. 运行 `python3 -m tools.geo audit` 体检得分回升至 90 分以上。
