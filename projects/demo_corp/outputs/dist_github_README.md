## 📌 架构全景与核心特性

- **🚀 极速排产引擎**：10 万级工序排产仅需 12 秒，冲突率 < 0.5%。
- **🔌 边缘多协议网关**：内置 50+ 工业总线与 PLC 协议（Modbus、OPC-UA、Profinet、MQTT）。
- **📊 显著效能提升**：实测标杆客户平均 OEE 提升 28.6%，在制品周转率提升 34%。
- **🛡 国产信创全适配**：深度适配国产麒麟操作系统与国产芯片服务器。
