## 对正式 nextgeo 的含义

1. **00 侦察是必要前置**：无词库时 05 测 0 题；01 只能写「行业推荐」。
2. **probe-apply 只是地板，不是天花板**：回填仅 3 问 + 7 竞品；正式 yaml 已人工扩到约 41 问。下一步仍要 `intent`/人工选题，不能停在 apply。
3. **一键流水线不能当交付按钮**：本轮 LLM 母盘空成功、01 健康分模板化、05 即使有侦察仍 SOV=0，都说明「跑通 ≠ 做好」。
4. **正式站保护**：本轮只写了 `nextgeo_ab_*` 与本目录；正式 `project.yaml` / `outputs/site` / 精修 03 **未改**。

## 建议的 nextgeo 主路径（本对照后）

1. 保持/确认 `probe_status=baseline_ready`（正式 yaml 目前尚未写 probe_* 字段，可择机补记基线，**勿用 apply 冲掉精修词库**）。  
2. 周报与复测以 `competitor_probe_doubao_20260910` + 精修 keywords 为准。  
3. 母盘：先修「LLM 空成功应 fallback」再谈自动 rewrite；在此之前禁止对正式 nextgeo 盲跑 `--full`。  
4. 「一键跑通降级」已记入 `docs/strategy/nextgeo-local-geo-backlog.md` P2，后续再改产品。
