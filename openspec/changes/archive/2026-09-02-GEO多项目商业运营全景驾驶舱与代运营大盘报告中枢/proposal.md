# Proposal: GEO多项目商业运营全景驾驶舱与代运营大盘报告中枢

## Why (为什么做 / 业务背景与痛点)

1. **单项目操作模式无法支撑多客户规模化代运营**：
   - 经过前期持续演进，系统已成功落地 16 维全景资产，并在四大垂直行业母版（徐州轩辕、B2B重工、本地律所、连锁餐饮）全量实现 100% 齐套生产与商业结案确认；
   - 但目前在管理端（`web/index.html`）与命令行中，所有数据均以“单项目独立查看与离散操作”为主。当代运营团队承接 4 家甚至更多企业客户时，管理人员需频繁下拉切换，无法一屏总览多客户的整体健康度与资产分布。

2. **管理层与投资人商业汇报缺乏全局驾驶舱**：
   - 缺乏一张面向企业创始人、交付总监与投资人的**全局宏观大盘（Executive Master Dashboard）**；
   - 无法一键汇总回答：“全平台目前托管了多少数字资产？总计为客户创造了多少年化商机价值与等效节省？平均 SOV 表现如何？有没有客户处于履约危险期或遭遇合规/注入风险？”

3. **规模化并发代运营与批量自动化需求**：
   - 缺乏轻量只读健康巡检、跨行业横向对比与自动化生成《GEO代运营全域多项目执行与商业回报大盘报告.md》的决策中枢，无法满足月度例会、季度复盘与规模化续费公关需求。

---

## What Changes (改动范围)

1. **研发多项目全景商业运营与聚合引擎 (`tools/geo/portfolio.py`)**：
   - `get_portfolio_summary() -> dict`：自动扫描系统合法项目（严格排除 `_template`、隐藏目录），优先读取已落盘 JSON，汇总统计四大核心维度：
     - **规模指标**：托管项目总数、通过全额结案项目数、16 维资产平均齐套率、全网分发渠道总数；
     - **声量与效果**：全盘实测/投影 SOV（%）、平均竞对反超领先幅度（分）、平均 Citation 权威度（分）；
     - **安全与风控**：全盘注入防御免疫度均值（分）、全盘广告法合规违规残留总数（处）、死链告警数；
     - **商业财务估值大盘**：全盘年度服务费投入（约 ¥67,200 元）、全盘等效 SEM 竞价替代年化节省、AI 首推商机总估值、全盘数字资产沉淀估值、**全域综合年化商业总价值**（实盘约 ¥918,580 元）与**严谨组合投资回报率 Portfolio ROI**（约 +1266.9%）；
     - **各项目横向对比矩阵**：各项目履约分、SOV（区分实测与投影）、续约健康度、年化总价值与动态风险分级（`danger` / `warning` / `normal`）。
   - `run_portfolio_health_patrol() -> dict`：轻量只读全盘健康巡检，输出全局异动红黑榜（零副作用、不发 Webhook、不重跑 monitor）；
   - `generate_portfolio_executive_report() -> dict`：自动生成结构化《GEO代运营全域多项目执行与商业回报大盘报告.md》，收敛保存至 `reports/` 目录。

2. **CLI 命令行增强 (`tools/geo/cli.py`)**：
   - 新增 `geo portfolio` 子命令：
     - `geo portfolio`：终端高保真表格渲染全局多项目大盘概况；
     - `geo portfolio --patrol`：执行轻量健康巡检并输出风险红黑榜；
     - `geo portfolio --report`：生成并落盘全局大盘月报 Markdown 文件。

3. **后端 RESTful API 扩展 (`tools/geo/server.py`)**：
   - `GET /api/portfolio/summary`：获取多项目全景大盘聚合指标与各项目对比数据（需管理端鉴权）；
   - `POST /api/portfolio/patrol`：执行全盘只读健康巡检；
   - `GET /api/portfolio/report`：获取大盘执行报告内容或下载文件。

4. **Web 管理工作台交互升级 (`web/index.html`)**：
   - 首页顶部指标栏将原占位的硬编码“平均 AI 声量提升 +100.0%”替换为实盘动态的「全域年化总价值」与「组合投资回报率」卡片，保持 7 列网格布局不挤爆；
   - 顶部导航栏新增「📊 全域大盘驾驶舱」按钮，支持多项目横向对比矩阵、风险警报清单、一键全盘巡检与一键导出月度大盘报告。

5. **自动化测试与四母版实测验证 (`tests/test_portfolio.py`)**：
   - 覆盖多项目聚合汇总计算、组合财务量化统计、风险分级（徐州 warning / 其余 normal）、大盘报告生成与 API 端点校验。

---

## Capabilities (对外能力)

- **全域多项目商业资产规模与财务回报综合统计（实盘约 ¥918,580 年化价值大盘）**；
- **跨项目一键轻量健康巡检与风险异动红黑榜**；
- **结构化代运营全域月度大盘报告一键导出（规范存入 `reports/`）**；
- **Web 管理端多项目全局驾驶舱可视化对比与快速直达**。

---

## Impact (影响分析)

- **纯增量开发**：完全基于已有 `load_project_config`、`acceptance`、`roi`、`monitor` 等落盘 JSON 做聚合分析，零破坏现有单项目流程；
- **严格遵守规范**：仅在本地开发端（http://127.0.0.1:8088）测试，严禁向生产服务器发布；
- **双端协同约束**：开发完成后提交并推送到双远端，归档流程严格交由另一个 IDE（Cursor）在独立复审通过后执行。
