# Proposal: 首页战略流程五步卡片排版重构为一行三列大字号呼吸感布局

## 1. 背景 (Why)
用户反馈当前 5 列横排（`lg:grid-cols-5`）导致单张卡片横向空间过于狭窄（仅约 215px）：
- 标题严重折行（甚至折成 3 行），文字小（12~13px），整体逼仄挤压；
- 用户提议：“要不还是设计成一行三个吧？或者有什么办法，能够让文字更大更清晰？”

## 2. 变更范围 (What)
- 将战略流程重构为“一行三个大卡片（前 3 阶段）+ 第二行两张大卡片居中（后 2 阶段）”的优雅 3+2 对称阶梯流转布局；
- 单张卡片宽度从 215px 激增至 ~375px（增加 75% 空间）；
- 标题放大至 `text-xl sm:text-2xl font-bold`，杜绝碎折行；
- 正文字号全面提升至 `text-sm sm:text-base`，行距宽松舒展；
- 内边距提升为 `p-7 sm:p-8 rounded-2xl`，数字水印升级为 `text-5xl font-black`；
- 双端同步更新并保证 0 Emoji 违规。

## 3. 影响评估 (Impact)
- 完美兼顾“程序标准五步闭环”与“大字号清晰美观”，消除卡片逼仄感，视觉效果大气舒展。
