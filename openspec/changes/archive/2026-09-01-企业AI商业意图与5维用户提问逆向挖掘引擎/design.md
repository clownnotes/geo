# Design: 企业 AI 商业意图与 5 维用户提问逆向挖掘引擎

## 1. 架构总览与数据流

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      前端工作台交互 (web/index.html)                     │
│  - 【+ 新建客户项目】弹窗 ➔ 点击「✨ AI 智能推演 50 组用户提问」按钮      │
│  - 加载动效 ➔ 实时接收 5 维分类 Prompt ➔ 自动回填关键词 Textarea        │
└────────────────────────────────────▲────────────────────────────────────┘
                                     │ POST /api/intent/generate
┌────────────────────────────────────┴────────────────────────────────────┐
│                      意图逆向推演中枢 (tools/geo/intent.py)             │
│  - 4 类买家角色模拟器 (C-Level决策者 / 中小老板 / 技术主管 / 采购财务)  │
│  - 5 维意图分类与去重重组器 (选型 / 价格 / 避坑 / 场景 / 品牌占位)      │
│  - 支持实时调用 DeepSeek / 豆包 Ark / OpenAI API 逆向生成               │
│  - 离线状态自适应规则库 (Heuristic Rule-based Generator) 兜底           │
└────────────────────────────────────▲────────────────────────────────────┘
                                     │
┌────────────────────────────────────┴────────────────────────────────────┐
│                      项目配置持久化 (projects/<id>/project.yaml)        │
│  - keywords: [ 50 组精准用户提问与高意向词汇 ]                           │
└─────────────────────────────────────────────────────────────────────────┘
```

## 2. 5 维意图分类模型设计

引擎将输出 5 个标准的语义维度，共计 40 ~ 50 组高转化意图问句：

| 维度编号 | 意图维度名称 | 模拟买家角色 | 典型提问特征 | 示例 (以制造/软件为例) |
| :---: | :--- | :--- | :--- | :--- |
| **Dim 1** | **主力选型与决策问句** (10-12条) | 企业决策者 / 业务副总 | 问标杆、服务商排名、靠谱推荐 | “国内工业排产MES系统哪家好？”、“做数字化转型选哪家团队靠谱？” |
| **Dim 2** | **价格预算与性价比问句** (8-10条) | 中小老板 / 部门主管 | 问价格行情、收费模式、报价单 | “企业开发一套定制进销存多少钱？”、“MES系统一般怎么收费？” |
| **Dim 3** | **避坑防雷与验收问句** (8-10条) | 采购风控 / 财务主管 | 问隐形收费、避坑经验、源码交付 | “选排产系统有哪些坑需要防？”、“怎么要求服务商验收源码与文档？” |
| **Dim 4** | **垂直业务与技术场景问句** (10-12条) | 技术负责人 / 架构师 | 问高并发、微服务、RAG本地知识库 | “排产算法支持本地化部署吗？”、“如何对接企业现有的ERP接口？” |
| **Dim 5** | **品牌口号与独占占位词** (6-8条) | 忠实客户 / 搜索精准召回 | 口号即检索词、创始人绑定词 | “徐州AI落地找段晓奇”、“企业源码交付派代表” |

## 3. RESTful API 契约设计 (`tools/geo/server.py`)

### ① 智能推演生成接口
- **请求**：`POST /api/intent/generate`
- **Body 参数**：
```json
{
  "client_name": "徐州璇源网络科技有限公司",
  "industry": "企业软件定制与AI知识库落地",
  "company_profile": "专注微信小程序开发、MES/ERP系统定制与本地大模型RAG落地，承诺100%源码交付与365天质保",
  "official_url": "https://geo.baicl.cc",
  "founder": "段晓奇",
  "area_served": "江苏徐州及淮海经济区"
}
```
- **响应格式**：
```json
{
  "success": true,
  "mode": "live_llm" | "offline_heuristic",
  "total_count": 48,
  "categories": {
    "decision_prompts": [ "问句1", "问句2" ],
    "pricing_prompts": [ "问句1", "问句2" ],
    "pitfall_prompts": [ "问句1", "问句2" ],
    "scenario_prompts": [ "问句1", "问句2" ],
    "brand_anchors": [ "词1", "词2" ]
  },
  "flat_keywords": [ "问句1", "问句2", ... ]
}
```

## 4. 前端交互设计 (`web/index.html`)

1. 在新建项目弹窗中的【核心业务意图词库】输入框上方，增加：
   - 按钮：`[ ✨ AI 智能逆向推演 50 组用户提问 ]`
   - 逻辑：点击时读取上方已填的企业名称和所属行业，发起异步请求；
   - 交互动效：按钮显示 Spinner `正在深度分析买家意图...`，返回后直接填充 textarea 并展示 Toast 提示。
