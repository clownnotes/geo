# Design: 服务页交付物采购方视角三大硬核交付重构

## 1. 业务心智与架构模型 (Mental Model & Architecture)

### 1.1 采购方视角三维一体交付模型
企业采购决策人（总经理、CMO、市场总监）在采购专业服务时，评估的核心是“确定性、可落地性、长期 ROI”：

```
[企业采购决策闭环]
┌────────────────────────────────────────────────────────┐
│ 1. 现状摸底与导师路线                                  │
│    摸清全模型底细与竞品差距，提供 180 天分步实施路线图 │
└───────────────────────┬────────────────────────────────┘
                        │ 指导实施
                        ▼
┌────────────────────────────────────────────────────────┐
│ 2. 交钥匙实体官网与底座                                │
│    告别空洞文档，直接交付符合 GEO 标准的企业官网与知识库│
└───────────────────────┬────────────────────────────────┘
                        │ 上线护航
                        ▼
┌────────────────────────────────────────────────────────┐
│ 3. 服务期内常态化攻防护航                              │
│    全天候代客盯模型、盯竞品，防患于未然，偏见热补丁修复│
└────────────────────────────────────────────────────────┘
```

## 2. 最终交付物对比与文案规范

| 维度 | 原版（顾问黑话视角） | 新版（采购方确定性视角） | 采购方心智价值 |
| :--- | :--- | :--- | :--- |
| **交付物 1** | **GEO 现状诊断报告**<br>核心交付：评分表 · 问题清单 · 优先级路线图 | **《企业 GEO 就绪度审计与落地方案》**<br>核心实物交付：**《全模型心智审计报告》· 竞品占位差距清单 · 180天分步落地实施路线图** | 确立“导师”角色，不仅查问题，还给出一清二楚的落地路线，按部就班就能赢。 |
| **交付物 2** | **答案源内容资产**<br>核心交付：页面架构 · 内容模板 · 核心页面文案 | **符合 GEO 标准的企业官网与知识底座交付**<br>核心实物交付：**高权重 GEO 标准官网/部署包 · /llms.txt 与 Schema.org 协议接入 · 普林斯顿 9 因子企业权威知识库** | 彻底打消“客户拿了文案不会建网站”的烂尾恐惧，交钥匙交付实体官网与底层代码。 |
| **交付物 3** | **AI 引用监测机制**<br>核心交付：提示词库 · 监测追踪表 · 月度复盘框架 | **服务期内 AI 引用监测与竞品动态攻防护航**<br>核心实物交付：**每周多模型动态监控周报 · 竞品反超实时预警机制 · 偏见/幻觉知识热补丁修复服务** | 彻底打消“买个空白表格自己人肉测试”的疑虑，确立服务期内有人替我盯竞品、防风险、修偏见。 |

### 3.1 编码与视觉纪律
- **0 Emoji 彩色表情**：严禁出现任何 Emoji 图标；
- **DOM 平衡**：所有 `div` 与 `article` 容器标签必须成对闭合；
- **双端镜像绝对对齐**：`outputs/services/index.html` 与 `outputs/site/services/index.html` 保持 MD5 一致。
