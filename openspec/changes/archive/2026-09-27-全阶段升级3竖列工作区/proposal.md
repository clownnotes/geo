# Proposal: 全阶段升级3竖列工作区

## Why (为什么做)
1. **交互体验割裂**：目前阶段 0（现状摸底）已经完成了标准的 IDE 级「3 竖列工作区」（左栏资产树 + 中栏多 Tab 编辑打磨 + 右栏 SOP 动线 + 顶部看板与麦肯锡避坑手册），用户体验极为流畅专业；然而阶段 1 至阶段 5 依然停留在早期的单列卡片平铺和按钮堆叠形态，排版拥挤、交互逻辑不统一。
2. **缺乏唯一真相源（SSOT）**：阶段 0 的多 Tab 编辑、Markdown 渲染、文件保存与复制逻辑已经封装成熟，但阶段 1～5 各自有一套零散的 DOM 渲染与事件处理，维护成本极高，容易出现修了这里漏了那里的隐患。
3. **交付作业流不连贯**：交付专家在执行阶段 1 至阶段 5 时，需要清晰地看到“当前阶段有哪些资产文件（左）”、“在线打磨交付内容（中）”、“按顺序执行哪些动线步骤（右）”，3 竖列是承载标准化交付流水线的最佳形态。

## What Changes (改动了什么)
1. **抽象通用 Studio 核心组件岛**：
   - 将原 `step0-src` 升级通用化为 `geo-studio`（或通用配置驱动架构），一套组件通吃阶段 0～阶段 5；
   - 抽象各阶段元数据配置表（`stageConfigs`），统一管理各阶段的标题、定位、核心目标、备忘字段、资产分类、编辑器 Tab 类型以及 SOP 动线步骤。
2. **重塑阶段 1 至阶段 5 的 3 竖列工作区**：
   - **阶段一（AI 可见度商业转化诊断）**：
     - 左栏：商业诊断报告 MD、老板大屏 HTML、底座技术体检 MD。
     - 中栏：双 Tab（文字报告 MD + 老板大屏 HTML 实时高保真预览）。
     - 右栏：4 步标准动线（真抓底座 -> 直出初稿 -> 复制润色 -> 定稿大屏）。
   - **阶段二（AI 原生交钥匙官网交付）**：
     - 左栏：交钥匙整站 index.html、大模型索引 llms.txt、结构化数据 schema.jsonld、爬虫放行 robots.txt、VPS 反代配置 conf。
     - 中栏：专注大模型底座文本与代码编辑打磨（llms.txt / schema.jsonld / robots.txt / nginx.conf）；交钥匙官网全屏高保真效果通过点击按钮在新窗口/弹窗独立打开。
     - 右栏：3 步流水线（一键编译交钥匙整站 -> 验证大模型友好底座 -> 查看/复制 VPS 反代配置与导出源码包）。
   - **阶段三（普林斯顿 9 因子高权威内容重构）**：
     - 左栏：普林斯顿母盘 master.md、证据素材库 evidence.json、唯一真相源 truth.md、发前对照卡 diff.md。
     - 中栏：专注文档，纯粹展示普林斯顿高权威母盘正文 Markdown（支持实时编辑打磨与快捷保存）。
     - 右栏：折叠承载证据库管理（抓取单页/贴手册素材）、真相源清洗与冲突仲裁、发前对照卡比对与钉住母盘操作。
   - **阶段四（矩阵分发与定稿发布）**：
     - 左栏：按分发渠道清晰展示交付稿件列表（头条稿.md、知乎稿.md、公众号稿.md、问答稿.md 等）。
     - 中栏：专注当前选中稿件的 Markdown 在线精修定稿。
     - 右栏：SOP 动线面板承载「主问句与已确认事实对照卡 + 批量/单篇草稿生成 + 勾选放行与一键复制发布」。
   - **阶段五（首轮监测与结案验收）**：
     - 左栏：首轮声量监测数据 json、GEO 交付周报 html、客户结案验收单 html、各模型实测明细 csv。
     - 中栏：聚焦交付物可视化与预览（Tab 1: 4 维指标量化大屏与实测明细，Tab 2: 美化周报实时预览，Tab 3: 客户结案验收单对客格式）。
     - 右栏：流水线动线（执行实时声量监测/真机回填 -> 归因分析 -> 导出美化周报与签发结案验收单）。
3. **全局配套赋能**：
   - 顶部统一挂载 `StageHeader` 看板与交付备忘录；
   - 全局挂载 `MckinseyDrawer` 麦肯锡认知与避坑手册，补充阶段 1 至 5 专属的价值、为什么、怎么做说明。

## Capabilities (新增或修改的对外能力)
1. **全阶段一致的工作台交互**：所有阶段具备统一的资源树浏览、多 Tab 切换、代码/Markdown 高亮编辑、全屏预览、实时保存与一键复制能力。
2. **白盒 SOP 动线全闭环**：每个阶段右侧动线均清晰展示当前步骤、专属动作按钮、进度状态与通关下一步指引。
3. **低耦合配置驱动**：后续新增阶段或微调阶段资产，仅需在配置表中增删字段，无需重复编写复杂的 HTML 骨架。

## Impact (受影响的部分)
1. `index.html`：各阶段旧有的平铺 DOM 结构（`panel-step-1-diag` 到 `panel-step-5-acceptance`）将退役，统一收敛为通用 Studio 容器挂载点。
2. `step0-src/`（升级为通用 Studio 源码）：升级扩展 `Step0App.vue`（或 `GeoStudioApp.vue`）以支持阶段参数入参，右侧 `StudioSop.vue` 增加根据当前 stage 动态渲染对应 SOP 步骤组件。
3. `assets/step0/step0.js`：通用 Studio 组件岛打包产物重新编译生成。
