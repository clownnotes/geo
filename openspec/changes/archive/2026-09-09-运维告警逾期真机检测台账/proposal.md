# Proposal: 运维告警逾期真机检测台账

## Why (为什么做)

当前「自动化巡检与告警」默认叙事是 **API 全量跑大模型探针**。现实约束是：

1. 管理端未必接入 DeepSeek/豆包 Key；即使用 Key，**API 问答 ≠ 用户网页未登录真搜**，SOV 易误导。
2. 仪表盘粉条只报「全量巡检尚未执行 + 告警开关」，**不能回答「哪家客户多久没做一次可信检测」**。
3. 阶段五已具备「真机实测回填」，但缺少运营主路径：**逾期提醒 → 点进客户 → 人工检测 → 统计落账 → 检测日志可查**。

产品共识（讨论拍板方向）：运维告警做成 **人工半联动为主**；全量 API 巡检降为可选加强项并标明口径。不做重型工单中台。

## What Changes (改动了什么)

1. **运维告警页升级为「检测台账」主页**  
   - 列表：每家托管客户的「上次真机检测时间 / 覆盖词数 / 最近 SOV / 逾期状态（正常·将逾期·已逾期）」。  
   - 一键进入该客户流水线「大模型问答探针 / 真机回填」。  
   - 仪表盘粉条改为摘要：「N 家已逾期 / M 家将逾期」，点进运维告警。

2. **逾期规则（可配置，默认钉死）**  
   - 距上次**有效真机检测** ≥ `warn_days`（默认 **7**）→ 将逾期（黄）。  
   - ≥ `overdue_days`（默认 **14**）→ 已逾期（红）。  
   - 「有效」定义：至少完成约定 **P0 词包**中不少于 `min_p0_hits` 条真机回填（默认与 P0 词数相同，或 ≥1 先可落地再收紧——见 design）。

3. **检测日志**  
   - 每次真机回填/（可选）机器巡检写入统一日志：时间、项目、操作者、模式（真机/API/离线）、词条摘要、当次汇总 SOV、原始回填引用。  
   - 运维页可按客户筛选查看；支持环比（相对上一条有效真机日志）。

4. **口径分层（文案与开关）**  
   - **主路径**：真机半联动。  
   - **次路径**：`geo patrol --all` / 全量巡检按钮保留，UI 标注「机器测，仅供参考」；其结果不得单独冒充「已完成真机周检」清空逾期（除非显式配置允许，默认不允许）。

5. **轻提醒（P1，可本期接口预留）**  
   - 配置项：是否把「逾期清单」推到现有企微/飞书 Webhook（周摘要），避免只躺在页面上。

### 非目标

- 不新建独立审批/工单系统。  
- 不强制本期必须接入大模型 Key。  
- 不删除现有 `patrol` / `monitor` 能力，只改运营主路径与逾期判定口径。  
- 不做业务员端登录隔离。

## Capabilities (新增或修改的对外能力)

| 能力 | 说明 |
|------|------|
| `GET /api/ops/check-ledger` | 全量客户检测台账（逾期状态、上次真机时间、覆盖、最近 SOV） |
| `GET /api/ops/check-logs?project_id=` | 检测日志列表 |
| 真机回填写日志 | `manual-ingest` 成功后追加一条 `check_log`（或等价落盘） |
| 运维告警 UI | 台账表 + 日志抽屉/分区；全量巡检降级文案 |
| 仪表盘摘要 | 逾期计数替代「仅尚未执行全量」的单一叙事 |
| 通知设置扩展 | `warn_days` / `overdue_days` /（可选）周催办开关 |

## Impact (受影响的部分)

- `web/index.html`：`home-ops`、仪表盘巡检条、通知设置弹窗文案。  
- `tools/geo/server.py`：台账/日志 API。  
- `tools/geo/monitor.py` / `patrol.py` 或新建 `tools/geo/check_ledger.py`：逾期计算、日志读写。  
- `data/` 或 `projects/*/outputs/`：检测日志存储（见 design）。  
- 复用：`/monitor/manual-ingest`、`05_manual_probes.json`、`history.db`。

## 验收标准

1. 运维告警能按默认 7/14 天标出将逾期/已逾期客户；无真机记录视为已逾期（或「从未检测」单独态，见 design）。  
2. 从台账一键进入对应客户真机回填；回填成功后台账时间刷新、日志多一条。  
3. 仅跑离线摸底或仅跑 API 全量（默认配置下）**不**把逾期清成「正常」。  
4. 文案无 Emoji；全量巡检按钮旁有「机器测，仅供参考」说明。  
5. 本地 `:8088` 可演示：造一条过期数据 → 列表变红 → 真机回填 → 变正常 + 日志可见。
