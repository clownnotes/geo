# Proposal: 开发者与写文同事双轨视界彻底解耦与全阶段白盒流水线复原

## Why (为什么做)

1. **拒绝打补丁，杜绝改一个页面漏五个页面**：
   - 之前在做“防泄密”时，代码产生了严重的局限性和一刀切打补丁思维：为了不让运营人员看到 Prompt，简单粗暴地在多个页面物理删除了代码，导致**全系统多个阶段全面被误伤**。
   - 必须通过面向对象思维做全量地毯式盘查，一次性彻底根治从阶段 0 到阶段 5 的全部角色错位与功能残缺，坚决不再一个页面一个页面打补丁。

2. **全量盘查发现的 6 大误伤与错位**：
   - **阶段 00（豆包摸底）**：开发者的 Cursor 出题、反重力（Antigravity）自动化问答闭环被连根拔起，只剩下手工一条条复制。
   - **阶段 01（现状诊断）**：开发者的步骤 ③（复制给 IDE 润色）与步骤 ④（追加豆包实锤）被删；写文同事面对重叠的 ①（抓底座）和 ②（0.01 秒死模板，没调 AI），核心小毛驴被埋没。
   - **阶段 02（站点底座）**：整站源码包（`.zip`）下载按钮没有角色限制，写文人员能一键搬走整站源码。
   - **阶段 03（9因子语料）**：9 因子核心语料库全文复制未限制角色，容易触发泄密或 403 弹窗。
   - **阶段 04（矩阵分发）**：开发者的【IDE 工地】（复制改写包开工、复制写回口令落盘）与全渠道 SOP 派单卡被整块删除；写文同事的纯网页闭环缺少明确指引。
   - **阶段 05（商业验收）**：商业 ROI 测算与服务费财务看板（大客户续费谈判底牌）完全暴露给写文同事。

3. **双轨视界彻底解耦的面向对象终极方案**：
   - **开发者视界（`data-geo-dev-only`）**：100% 恢复全套白盒流水线、IDE 深度协同武器库、源码/整包导出与商业 ROI 大盘；
   - **写文同事视界（`data-geo-writer-only`）**：纯粹极简黑盒闭环，一键调用小毛驴大模型算力，在网页内改字定稿，不接触任何底层代码、配方与商业机密。

## What Changes (全量 6 阶段改动清单)

| 阶段 | 开发者一定要有的（Developer 视界 `data-geo-dev-only`） | 写文同事专用的（Writer 视界 `data-geo-writer-only`） | 根治措施 |
| :--- | :--- | :--- | :--- |
| **00 豆包摸底** | **复原自动化工具卡片**：Cursor 出题、反重力问答指令、落盘命令（仅开发者）。现码函数已改成拒绝复制的空壳，UI 卡片已从表单拿掉。 | **保留本页手工工位**：本页出题 → 去豆包问 → 确认写入。 | 在 `web/step0-src` 用 `bridge.isDeveloper`（或等价）互斥展示；改完必须 `npm run build:step0` 更新 `web/assets/step0/step0.js`。 |
| **01 现状诊断** | **复原 4 步白盒流水线**：①真抓 → ②直出客观初稿 → ③复制报告给 IDE 润色 → ④追加豆包实锤给 IDE；保留老板版/工程师双 Tab。现码里 ③④ 的 JS 已变成「改成在网页里做」的空提示，要恢复真复制/真接口（仅开发者可见）。 | **一个主按钮**：白话名如「用小毛驴写商业诊断」。**不能**只调 `mode=interpret`：现码 interpret 要求已有摸底结果。正确顺序：没有摸底就先 `crawl`，再 `interpret`（会调小毛驴并重写老板版/技术版报告）。工程师 Tab 对写文同事隐藏。 | 开发者白盒与写文一键互斥（`data-geo-dev-only` / `data-geo-writer-only`）。 |
| **02 站点底座** | 一键编译整站、查看/下载 Nginx 反代配置、**【导出源码包 (.zip)】**。 | 纯只读站点预览（确认客户官网能不能打开）；**隐藏源码包下载**。 | 给【导出源码包 (.zip)】补上 `data-geo-dev-only`。 |
| **03 9因子语料** | 增量重构/强制全量、唯一真相源、**【复制 9 因子全文】**、RAG 检索诊断。 | 查看【企业核心事实清单】（核对品牌、电话、产品）；**隐藏 9 因子全文复制**。 | 给【复制全文】补上 `data-geo-dev-only`，防止配方外泄与 403。 |
| **04 矩阵分发** | **复原【IDE 工地】**：复制改写包去 IDE 批量重构、复制写回口令贴回落盘；复原各渠道 SOP 派单卡。 | **纯网页写作闭环**：点【小毛驴 AI 智能改写】-> 网页文本框改错别字 -> 点【保存定稿】-> 复制去平台发布。 | 恢复 IDE 工地挂 `data-geo-dev-only`，写文同事工位纯网页闭环。 |
| **05 商业验收** | 结案打分台账、**【商业 ROI 测算与服务费续约预测】**、**【下载全套成果 ZIP】**。 | 查看 6 维合同履约验收结果、打印盖章结案单；**隐藏商业 ROI 财务看板与整包 ZIP**。 | 给商业 ROI 看板整块补上 `data-geo-dev-only`，保护商务机密。 |

## Capabilities (对外与系统能力)

- **全域彻底解耦，零相互污染**：开发者使用完整的白盒工程与 IDE 协同能力；写文同事享受纯粹的一体化小毛驴闭环。
- **彻底消灭 403 弹窗**：写文同事在所有页面都看不到任何越权按钮，视线清爽，不会误触报错。
- **全链路资产防线**：整站源码 ZIP、9 因子全文复制、商业 ROI 看板、整包 ZIP、IDE 口令对写文同事无入口；服务端既有开发者后缀继续兜底。

**明确回滚点**：本期会**有意**恢复开发者 IDE 协同（撤销 2026-09-19「去 IDE 化」里对开发者的空壳 stub），写文同事仍禁止接触 IDE 口令。
