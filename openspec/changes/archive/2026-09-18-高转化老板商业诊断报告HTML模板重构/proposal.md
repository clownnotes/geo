## 1. 为什么做（Why）

### 1.1 业务背景与现状痛点
在上一阶段开发中，我们成功将【阶段一：测算诊断】拆解为**“老板商业转化版”**与**“工程师技术体检版”**两大体系，并完成了“老板心理学 7 步法”的 Markdown 初稿直出。

然而，在交付给客户的最后一公里上，存在严重的体验代差：
1. **现有 HTML 导出过于简陋**：管理端点击【下载老板商业报告 (HTML)】导出的网页，仅是把 Markdown 放入极简的灰白容器中，没有视觉重点，像一份未经排版的草稿；
2. **缺乏商业震撼力与签单心理学**：师弟在实战中拿到的参考样板（`邻里GEO-AI可见度诊断报告（转化版）.html`）具备极高水准的转化设计——深色沉浸式 Hero 头图、34 分醒目警示环、AIVO 四维雷达图与行业基准对比柱状图、9 组真实问答证据红绿排版、竞品占位透视与 30 天前后对比表；
3. **未能程序化自动化生成**：目前该高转化页面为手工静态文件，未接入 GEO 系统的自动化流水线；当更换其他客户项目（如 `demo_corp`、`xuzhou_xuanyuan`）时，无法一键生成对应的数据报告。

### 1.2 核心目标
将这份高转化水准的 HTML 页面，作为全系统【老板商业诊断报告 (HTML)】的**官方渲染基准**，实现：
- **数据 100% 程序化动态组装**：自动从 `project.yaml`、`audit_metrics.json`、`competitor_probe_doubao_*.json` 及商业诊断 Markdown 中提取真实数据并注入模板；
- **自包含离线单文件**：内联高质感 CSS 与原生 SVG 图表（雷达图、环形图、进度条），零外部 CSS/JS 依赖，客户在微信/飞书/Safari/Chrome 中双击或点击链接秒开；
- **严格遵守 0 Emoji 商业合规红线**：将参考样板中残留的 Emoji（如 🔴🟢🟡⚠️）彻底替换为符合严肃商业审美的 CSS 状态徽章（如 `.dr-badge--danger`、`.dr-badge--success`）；
- **管理端闭环联动**：在 `http://localhost:8088/#project=nextgeo&view=step-1-diag` 中，点击【下载老板商业报告 (HTML)】即可秒级下载该高质感报告；在【客户报告链接】中可直接在线预览。

## 2. 改动范围（What）

1. **新建高转化 HTML 渲染生成器模块**：
   - 在 `tools/geo/` 下封装专门的老板商业诊断报告 HTML 构建引擎 `boss_report_html.py`（或整合进 `share.py`）；
   - 解析项目配置、网络真抓指标与大模型探测数据，计算 AIVO 四维得分（基建、引用、搜索、认知）及评级。
2. **原生纯 SVG 图表与自包含样式体系**：
   - 原生 SVG 环形评分进度圈（可动态计算 stroke-dashoffset 与颜色）；
   - 原生 SVG AIVO 四维等权雷达网图；
   - 带有 60 分行业参考基准线的横向百分比对比条；
   - 问答结果占比环形分布图（未提及 / 提及但错误 / 准确）。
3. **数据结构与模块化动态映射**：
   - **Hero 模块**：客户名称、一句话定性、状态徽章、评分与评级；
   - **概览卡片**：诊断结论提炼；
   - **好消息模块**：技术底座 6 项达标表格、3 大特征卡片；
   - **坏消息模块**：9 组问答实测证据对照表、3 类流失询盘卡片；
   - **竞品透视模块**：AI 实测竞品列表、缺口镜像与品牌名称误读风险提示；
   - **四步破局与 30 天愿景**：优先级动作表、30 天前后对比表；
   - **转化 CTA 模块**：体验包说明、微信/电话/官网联系方式；
   - **评测元信息**：数据真源免责与版权说明。
4. **管理端与 API 接口升级**：
   - 升级 `/api/projects/{id}/export-audit-html?view=boss` 接口，直接返回该高质感自包含 HTML；
   - 升级 `/share/{token}` 客户只读交付门户中的老板报告视图。

## 3. 对外能力（Capabilities）

- **能力 1**：`python3 -m tools.geo audit <project_id>` 在生成 Markdown 的同时，自动在 `outputs/` 输出排版精美的 `01_企业AI可见度商业诊断报告.html`。
- **能力 2**：管理端 `web/index.html` 阶段一【老板商业转化版】点击【下载老板商业报告 (HTML)】时，直接触发下载这份自包含高转化 HTML。
- **能力 3**：客户专属分享门户 `/share/{token}` 在查看体检报告时，支持呈现与该 HTML 视觉一致的高端商业大屏。

## 4. 影响分析（Impact）

- **向后兼容**：底层工程师技术体检版（`01_企业底座技术体检审计报告.md / .html`）完全保持独立与原生工程样式，互不影响。
- **性能与体积**：报告 HTML 保持为自包含单文件（约 30~50 KB），无外部 CDN 脚本依赖，打开速度极快。
- **规范红线**：严格杜绝 Emoji，遵循普林斯顿 9 因子，开发与测试全程锁定在本地端口 `:8088`，严禁私自向生产服务器推代码或重启进程。
