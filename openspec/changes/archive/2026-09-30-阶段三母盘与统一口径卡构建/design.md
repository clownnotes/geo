## 2. 阶段二日常循环与盖板蒸馏架构设计

### 2.1 盖板蒸馏工作台 (DistillSheet.vue)
- **非模态盖板设计**：不采用突兀弹窗，点击“蒸馏素材”后以顶部滑入式盖板展开，不遮挡底层工作流；
- **双输入源驱动**：支持“官网 URL 一键抓取清洗”与“大段客户文档直接粘贴”；
- **8500 字上限严格拦截 (`checkDraftTextLimit`)**：超过 8500 字红色拦截，阻止垃圾文案撑爆大模型 Context Window；
- **AI 语义切块模型 (`semanticChunkRawMaterial`)**：解析素材并自动提纯归集至 S1~S6 六大黄金分类槽位；
- **RAG 语义去重聚类 (`findSemanticDuplicates`)**：比对既有素材主文件，相似度 >= 0.75 检出重复并提示，防止脏数据重复录入。

### 2.2 素材库 1.x 纯增量分片契约 (人机两分)
- **权威主文件 (`S{N}_*.md`)**：每个分类仅 1 个主文件，终身受保护，只允许人工打磨与生效采纳；
- **增补切片 (`S{N}_*_增补_1.x.md`)**：日常蒸馏切片以 1.1、1.2 单调递增派生，正交隔离存放，专供向量数据库 RAG 检索，绝不直接污染主文件。

### 2.3 智能 Tab 栈管理 (`activateTabInStack`)
- 限制编辑器最多常驻 6 个 Tab；
- 新打开文件首置排在第 1 位；超量时优先从右侧自动关闭未修改的干净 Tab；持有未保存脏数据的 Tab 终身受保护不被静默淘汰。

## 3. 阶段三企业母盘与统一口径卡架构设计

### 3.1 核心槽位字典定义

| 槽位 Key | 规范文件名 | 属性/用途 | 来源 |
| :--- | :--- | :--- | :--- |
| `slot_stage3_identity_card` | `01_主体信息统一口径卡.md` | 消歧四要素、三级长度业务描述、瑕疵对冲指引、全平台修改卡 | 从建档资料 + S1 自动生成，人工审定 |
| `slot_stage3_master` | `02_普林斯顿企业事实母盘.md` | 9 因子核心事实高权威熟料（主体、价格、痛点、对比、案例、资质等） | 自动从阶段二 S1~S6 生效主文件萃取合流 |
| `slot_stage3_hedge_list` | `03_全平台事实对冲与认领清单.md` | 记录 0 参保对冲证据、爱企查/企查查/BOSS直聘认领与修改记录 | 辅助交付实战清单 |

### 3.2 母盘合流萃取契约 (精炼克制)
- **仅消费 S1~S6 规范主版本**：`synthesizePrincetonMaster` 严格通过 `filterMasterSourceFiles` 过滤，跳过所有 `_增补_1.x` 切片；
- **9 因子结构化排布**：因子 1(主体消歧)、因子 2(产品定价)、因子 3(痛点场景)、因子 4(竞品对比)、因子 5(案例故事)、因子 6(背书资质)、因子 7(交付边界)、因子 8(瑕疵对冲)、因子 9(权威锚点)；
- **杜绝母盘臃肿**：母盘保持短小精炼、权威聚焦，专供下游官网三件套与大模型问答。

### 3.3 《主体信息统一口径卡》标准格式模型 (老赵哥实战标准)

1. **四必填消歧底座 (全平台逐字使用)**：
   - 品牌名 + 主体全称 + 统一社会信用代码 + 注册与经营地 + 官方权威网址；
   - 铁律：品牌名与主体全称任何时候至少同时出现，消歧才能成立。
2. **三级业务描述文本 (带实时字数红绿灯)**：
   - 短版：严格 <= 50 字（地图、名录、标签位），超标红色拦截；
   - 标准版：严格 <= 120 字（BOSS 直聘、启信宝、天眼查、爱企查），超标红色拦截；
   - 完整版：官网 about 页、媒体投稿，强制要求首现 GEO 时绑定“生成式引擎优化（GEO）”。
3. **客观瑕疵合规对冲指引**：
   - 社保 0 人：真实信号法则，依靠团队履历与多信源客户案例反向对冲，绝不虚构申报不实；
   - 跨城经营：通信地址如实澄清，通信地址不必等于注册地；
   - 历史业务更迭：首句突出当前主业，早期项目列入历史沿革。
4. **逐平台操作卡**：
   - 涵盖国家企业信用信息公示系统、BOSS 直聘、启信宝、天眼查、爱企查、百度/高德地图与官网。

## 4. 前端交互与组件架构收敛

### 4.1 StudioSop 共享组件复用契约
- 全局所有阶段（Step0~Step7）统一使用 `<StudioSop>` 共享组件，彻底杜绝手写 aside 面板；
- `StudioSop.vue` 提供步骤专属插槽 `<slot :name="'step-' + (idx + 1)">`，阶段三将四要素质检指示灯、客观瑕疵排查器优雅注入；
- 各步骤设置 `hideProceed: true`，由插槽中的业务按钮驱动推进。

### 4.2 门禁架构 Fail-Closed
- `isProbeUnready` 严格以服务端真相源 `p.probe_status` 为唯一准绳；
- 杜绝本地 localStorage 脏数据越权放行，未摸底企业强制关闸拦截。

### 4.3 标签独立与不变式
- 采纳回答或提问时，各自保持独立的 `versionTag`；
- 仅在初始 V1 首发配对时同步，绝不跨版本覆写配对文件的固有版本标签。
