# Proposal: 工业级双层侧边栏导航重构与小毛驴色系升级

## Why (为什么做)

1. **消除纵向多层叠罗汉，释放有效视口**：当前系统采用“顶部总 Header + 场景横向 Tab + 5 步流水线横向向导条 + 页面内子 Tab”的 4 层横向堆叠模式。用户进入项目后，上半屏被大量工具条霸占，真正的工作区（如文章富文本、探活表格、诊断报告）被挤压在逼仄的下半屏，视觉感受陈旧且产生严重操作压迫感。
2. **向现代工业级 B2B SaaS 体验升级（对标 Bihuo GEO 与 Nextdoor Admin）**：参考 `geo.bihuogeo.com/#/dashboard` 与 `http://100.83.64.112:3002/admin/` 的成熟拓扑，现代企业级系统普遍采用“左侧一级/二级菜单导航栏 + 顶部轻量级 Header + 右侧沉浸式工作区”标准架构。这样既满足了线性流水线交付，又支持日常按需直达具体功能模块。
3. **视觉全面注入小毛驴 AI 品牌设计系统**：统一对齐 `http://100.83.64.112:3002/admin/` 的核心视觉规范：以小毛驴品牌紫（`#7c5bf5`）为主色调，搭配 Slate-900（`#0f172a`）、Slate-50（`#f8fafc`）与细腻中性线框（`#e2e8f0`），彻底告别散乱的配色，呈现沉稳、专业、高质感的科技品牌形象。

## What Changes (改动了什么)

1. **整体布局拓扑重构（左右水平分栏，高度铺满视口）**：
   - 整体架构由上下流动改为全屏网格/弹性分栏布局（`flex h-screen overflow-hidden`）：
     - **左侧侧边栏 (Sidebar，固定宽度 240px)**：
       - 顶部：GEO 系统 Logo 与品牌徽标；
       - 客户项目快速切换器（下拉即时切换当前项目，支持新建项目）；
       - 核心功能导航树：分为 5 大一级场景分组，包含带细腻图标的二级菜单子项，当前激活项高亮展示；
       - 底部：管理员账号状态、系统版本号与退出登录入口；
     - **顶部轻量 Header (Top Bar，高度 52px)**：
       - 动态面包屑导航（如：`徐州璇源 / 交付生产线 / 矩阵分发与外链探活`）；
       - 右侧全局快捷动作区（一键跑通流水线、一键打包导出 ZIP、服务探活状态）；
     - **右侧沉浸式主工作区 (Main Workspace，自适应填充，内部独立滚动)**：
       - 取消顶部冗余的横向 3 层步进条；
       - 根据左侧二级菜单路由，独立渲染各功能面板，首屏内容展示面积提升 80% 以上。
2. **功能导航树架构梳理（管理台：一级分组标题 + 二级菜单）**：
   - 交互定调：对标常见 Admin 后台——左侧**一级只做分类标题（可折叠）**，**二级菜单才是可点击入口**；一眼能按业务域找功能，不再用顶部横向场景 Tab。
   - **分组 1：项目概览**（客户看板、词库与意图）；
   - **分组 2：交付流水线**（诊断 → 底座 → 语料 → 分发探活 → 验收，5 个二级项）；
   - **分组 3：监测运维**（周报、探针、巡检、客户交付物、半衰期自愈、声誉危机、普林斯顿复检）；
   - **分组 4：进阶攻防**（竞品护城河、检索 RAG、信源归因、对抗鲁棒——按原武器库主题升为二级，面板内保留原 Modal 按钮）；
   - **分组 5：系统设置**（大模型中枢、离线导出）。
   - **禁止**再用含糊的「工具合集」大口袋；原 boost/ops 入口全部落到有名字的二级菜单下。
3. **小毛驴 AI 专属色彩体系落地**：
   - 主题色变量与主色调收敛至 `#7c5bf5`（Nextdoor Violet）；
   - 侧边栏活动项使用 `bg-[#7c5bf5]/10 text-[#7c5bf5] font-semibold border-r-2 border-[#7c5bf5]`；
   - 核心 CTA 按钮统一为 `bg-[#7c5bf5] hover:bg-[#6846e3] text-white shadow-sm`；
   - 严格遵循全局规范：0 彩色 Emoji 表情，全部使用精美 Lucide 矢量线框图标。
4. **URL 路由模型收敛**：
   - 废除原先以 `step` 为主的混杂 Hash，统一为 `#project={id}&view={module_key}`（**禁止**前导 `/`，以免 `URLSearchParams` 把键解析成 `/project`）。
   - Step 2 站内子 Tab 等局部状态可继续附带 `&tab=site.html` 等次级参数，不升为一级路由。
   - 旧链接 `#project=xxx&step=4` 必须自动映射为对应 `view` 并 `replaceState` 回写。

## Capabilities (新增或修改的对外能力)

1. **双层侧边栏导航组件**：支持多租户项目即时下拉切换、场景大类折叠与二级功能直达；
2. **小毛驴 AI 设计规范全面适配**：统一调色板、统一组件圆角（`rounded-xl`）与字体层级；
3. **沉浸式主工作区布局**：视口纵向高度 100% 释放给业务内容。

## Impact (受影响的部分)

- **核心受影响代码**：
  - `web/index.html`：重构最外层布局容器，注入左侧侧边栏 DOM 结构与顶部面包屑栏，更新路由分发与激活状态逻辑，替换调色盘样式变量。
- **架构零耦合保障**：
  - **后端 API 100% 保持不变**：所有数据接口与流水线执行命令完全原封不动；
  - **现有功能 100% 兼容保持**：头条知乎分发、富文本复制、外链探活、审计日志弹窗等各模块作为独立视图挂载在工作区内部，原有交互与业务逻辑完全不受任何影响。
  - **进阶/运维工具不删不丢**：原 `scene-boost` / `scene-ops` 按主题升为命名清晰的二级菜单；面板内保留原 Modal/`onclick`，禁止删除入口。
  - **未选项目态**：项目列表看板仍为独立入口；选中项目后侧边栏展开完整导航树。
