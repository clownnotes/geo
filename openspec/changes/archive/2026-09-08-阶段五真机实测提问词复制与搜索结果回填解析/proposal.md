# Proposal: 阶段五真机实测提问词复制与搜索结果回填解析

## Why (为什么做)

1. **解决普通 API 不联网的滞后盲区**：
   - 现有的阶段五「执行实时声量检测」主要依赖后端调用大模型 API（`probe_llm_live`）。但标准大模型 API 默认走预训练静态底座，无法实时检索最新抓取的互联网网页（如知乎、头条新发文章）。
   - 这导致运营人员在阶段四刚分发完矩阵文章后，若立即跑 API 探测，可能无法测出最新上榜的实时增量效果。

2. **消除大模型 API Key 配置门槛与成本**：
   - 很多用户或现场交付工程师在演示或未申请商业 API Key 时，系统只能走“离线基准测算”，缺少真实的交互数据；
   - 支持免登录真机实测回填，能够让用户在零 API 成本、零配置的前提下，获取 100% 真实的线上效果验证。

3. **满足商业交付中最有说服力的“真机无痕实测”需求（Ground Truth）**：
   - 用户明确提出核心业务场景：**直接生成对应平台的提示词，运营/销售直接到对应平台免登录/无痕搜索，然后将搜索结果粘贴回填**；
   - 在企业级高客单客户验收结案时，客户最认可的不是后台的 API 跑分，而是当面打开无痕浏览器（避免历史账号画像与千人千面干扰）、在 DeepSeek / 豆包输入采购选型词，亲眼看到品牌排在第一位并引用了官方文章；
   - 现有系统缺少“分平台提问词一键复制”和“网页端完整结果回填解析”的标准闭环，无法将真机实测的客观数据自动化沉淀进验收单与商业 ROI 看板。

---

## What Changes (改动了什么)

1. **阶段五新增「真机无痕实测助手」交互组件**：
   - 在阶段五顶部控制栏增加「真机实测回填」入口（挂载于 `panel-step-5-acceptance`）；
   - **分平台拟真采购提问词体系**：针对项目配置的核心商业意图词，区分 DeepSeek（侧重深度技术选型评测）、豆包（侧重字节头条生态与应用场景）、元宝（侧重微信公众号与私域干货）、Kimi（侧重长文本与深度研报）生成定制 Prompt；
   - **无痕免登录实测指引**：提供平台直达链接，并明确提示“使用浏览器隐身/无痕模式免登录访问，开启联网搜索，消除个性化推荐干扰”；
   - **网页回答粘贴与纯文本安全清洗**：提供回填输入框，支持一键粘贴大模型完整回答；前端与后端自动执行 HTML/Script 剥离纯文本化，严格设置 100KB 上限防撑爆。

2. **后端新增真机数据提取与合并回灌引擎**：
   - 抽象大模型回答通用语义提取器，解析出：**品牌提及位次（Rank）、Top 1/Top 3 达成情况、竞品拦截、外链 Citation 域名加权渗透**；不仅支持标准 URL，亦兼容中文脚注文本（如“来源：知乎专栏”）；
   - **真机数据持久化与回灌铁律**：
     - 真机实测数据单独持久化写入 `outputs/05_manual_probes.json`；
     - 合并入《`05_企业AI可见度与声量追踪周报.md`》，统一使用中立的文本 Tag 标注 `[真机实测]`（严禁彩色 Emoji）；
     - `run_monitor` 全量重跑时，**必须**从 `05_manual_probes.json` 回灌真机记录（同键优先级：真机实测 > 实时 API > 离线估算），坚决杜绝重新执行监测导致真机验收数据丢失。

3. **大盘指标与商业 ROI 实时联动**：
   - 回填并解析成功后，即时触发前端 4 维核心指标卡（SOV、DeepSeek首推率、豆包首推率、权威信源评分）与商业 ROI 价值折算看板的动态刷新；
   - 词库过大体验防护：针对大词库（如 50+ 组词），前端选择器默认展示前 30 个高频词并提供即时过滤搜索框，防范弹窗卡顿。

---

## Capabilities (新增或修改的对外能力)

1. **`GET /api/projects/{id}/monitor/prompts`**：
   - 获取项目核心词的各平台拟真提问词（支持 deepseek/doubao/yuanbao/kimi 细分）、平台直达 URL 与免登录无痕测试指引。
2. **`POST /api/projects/{id}/monitor/manual-ingest`**：
   - 接收用户从网页端复制的真实回答内容，校验合法性并执行纯文本脱敏；
   - 自动执行位次解析、竞品判定与 Citation 提取，更新周报与持久化 JSON，返回解析报告及与现网结构对齐的 `metrics`。
3. **前端「真机实测回填」弹窗**：
   - 提供“选词检索与定制 Prompt 复制 -> 打开平台无痕实测 -> 贴回解析并清洗 -> 刷新大盘与 ROI”的完整闭环。

---

## Impact (受影响的部分)

* **后端服务**：`tools/geo/monitor.py`（提取解析公共函数、真机回灌逻辑、生成/更新周报）、`tools/geo/server.py`（prompts 与 manual-ingest 两个 REST 路由）。
* **前端界面**：`web/index.html`（阶段五控制栏增加入口、新增真机实测回填弹窗、联动大盘与 ROI 刷新）。
* **交付物料**：周报《`05_企业AI可见度与声量追踪周报.md`》与持久化档案 `outputs/05_manual_probes.json`。
