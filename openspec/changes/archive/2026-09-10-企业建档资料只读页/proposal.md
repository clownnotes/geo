# 企业建档资料只读页

## Why

企业管理列表只能「进入流水线 / 下载 ZIP / 删除」，无法一眼核对**建档时填了什么**（名称、行业、官网、合作方、词库、竞品、联系人等）。交付过程中改口径、对账、交接时，常要翻 `project.yaml`，效率低且易看错。

流水线内「客户档案与总资产看板」目前只有名称 / ID / 官网三格摘要，**不是完整建档资料视图**。

## What

1. 企业管理列表增加「查看资料」入口（与「进入流水线」并列），不强制先进流水线。
2. 管理端只读展示建档主档（来自 `project.yaml`）：主体信息、服务腹地、联系方式、slogan/简介、核心价值、词库、竞品、合作方等。
3. 强化流水线侧「客户档案」页：同字段完整可读；可选链到证据库/真相源（只读摘要，本期不做编辑）。
4. 本期**不做**建档字段在线编辑（编辑另开变更）；不做客户侧公开分享。

## Capabilities

- 运营可在企业管理列表一键打开某企业的建档只读资料。
- 进入流水线后，「客户档案」页可完整对照建档字段。
- 数据来源明确：主档 = `project.yaml`；证据/真相源仅作次要入口提示。

## Impact

- 前端：[`web/index.html`](web/index.html)（列表操作、overview 面板或弹层）
- 后端：复用或轻量扩展 `GET /api/projects/{id}`（已返回 project 配置）；必要时补 `partner_name` 解析
- 不改客户分享门户、不改生产部署流程
