# Proposal：基于 www.baicl.cc 母版的极简 SaaS 交钥匙官网与可控预览发布

## 用户核心原话实录（第一真理源）

> “我希望这个网站是在我们 www.baicl.cc 官网基础上。做得一套 SAAS 网站，外观就统一一套，然后每个客户上传自己的 LOGO 还有一些什么信息。当然，多数可能是直接通过我们前面建企业资料时候就抓出来了。你能理解么？核心是要能被 AI 抓，同时也比较简单好维护。”
>
> “我希望设计得简单一点。根据客户的资料生成时，只需简单替换一些内容即可。如果客户没有自己的资料，就留白，也不要显示 logo，直接作为一个默认版，内容很少，只换个公司名、联系方式这些。”
>
> “至于你说的开关等功能，等真正需要做的时候，我们到时候再在静态页面里处理。反重力 2.0，帮客户编辑就可以了。”
>
> “刚开始，不用默认挂我们名下，因为你弄个客户代号，我还要去解析，就很麻烦。要解决如何让客户看的问题，就是在刚开始就在我们域名下面生成一个带文件地址的链接，比如说。claw.baicl.cc 然后带一套地址。这个地址点进去看，就是这个客户的信息。为了不影响 AI 抓我们的数据，这个地址我们可以手动开关，如果不需要展示。点一下关。就不会被公网看到就可以了。你觉得这样对么？”
>
> “关于你第 3 个，是不是自动这个也不重要，到时候只是一个做前端的事情，让 IDE 做就可以了。我们只要把提示词写好，写清楚，这个母版，该怎么改。让 IDE 知道就行了。一般客户都是快速生成，后面的再慢慢改。”

---

## Why

当前后端建站脚本 `src/tools/geo/scaffold.py` 生成的是一套早期写死的“本地软件外包”单页模板（包含硬编码的价格表和 Emoji 图标），既无法体现 `www.baicl.cc` 的专业 B2B 视觉与普林斯顿 9 因子信息架构，在客户资料不全时还会强行塞入不相关的假数据；同时，给每个新客户单独配置二级域名解析过于繁琐，急需一种“统一母版 + 极简替换 + 缺省留白 + 同域名路径预览且可一键开关”的标准化交付方案，实现 10 秒快速出初稿、后续交给反重力 IDE 按规范精修。

---

## What Changes

- **统一 SaaS 静态母版抽离**：以 `projects/nextgeo/outputs/site/`（`www.baicl.cc`）为视觉与结构基准，抽离一套可复用的统一 SaaS 静态母版（存放在 `templates/baicl-saas/`），全站采用纯静态 HTML + 内联防御性 CSS + 相对路径，确保 AI 爬虫直接解析且零外部样式崩溃风险。
- **极简字段替换与缺省留白机制**：重构 `src/tools/geo/scaffold.py` 建站编译逻辑，优先从客户既有建档资料（`project.yaml` / 传入参数）自动提取字段；**严格遵守“有则渲染、无则留白”原则**——未上传 LOGO 时不渲染 LOGO 图片，未填写业务/优势/FAQ 等扩展资料时直接隐藏对应板块，只保留公司名、品牌名、联系方式等基础默认版，彻底清除历史写死的软件外包假数据与 Emoji。
- **大模型底座三件套与相对路径合规**：编译时同步输出 `index.html`、`llms.txt`、`schema.jsonld`、`robots.txt`、`sitemap.xml`（全部使用相对路径），并继续严格尊重 `custom_site: true` 防覆盖锁，避免覆盖已被反重力 IDE 精修过的客户站点。
- **`claw.baicl.cc` 路径预览与手动公网开关**：设计 `https://claw.baicl.cc/<project_id>/` 统一路径托管与 Nginx 配置模板，无需为每个客户单独配置 DNS 解析；通过无状态开关标记（开启/关闭公网访问）实现一键切换——关闭时公网和爬虫直接收到 HTTP 404，开启时可正常预览，且与 `www.baicl.cc` 主站物理隔离。
- **反重力 IDE 母版精修提示词规范**：新增《SaaS 官网母版结构与精修指南》（`docs/specs/saas-site-master-guide.md`），写清母版区块标记、相对路径红线、普林斯顿 9 因子排版规则与防覆盖锁定方法，供后续反重力 IDE 直接为签约客户编辑静态页面。

## Impact

- **受影响代码与资产（GEO 仓）**：
  - 新增：`templates/baicl-saas/`（统一 SaaS 官网母版目录）
  - 修改：`src/tools/geo/scaffold.py`（改用统一母版编译、实现缺省留白、补齐 `sitemap.xml` 与预览开关辅助能力）
  - 修改：`src/tools/worker/handlers.py`（`handle_build_site` 透传可选覆盖参数并返回完整成品路径与预览路径）
  - 新增：`deploy/nginx_claw_preview.conf`（`claw.baicl.cc/<project_id>/` 路径托管、尾斜杠 301 重定向及开关门禁 Nginx 模板）
  - 新增：`docs/specs/saas-site-master-guide.md`（供反重力 IDE 使用的母版结构与精修提示词规范）
  - 新增：对应单元测试（覆盖“全量资料”、“极简默认版留白”、“无 LOGO 隐藏”、“`custom_site: true` 防覆盖”、“预览开关启停”）
- **跨仓与架构边界**：
  - 严格遵守前店后厂红线：GEO 后厂不连接 MySQL、不新建管理端页面，只负责静态模板编译落盘与无状态文件级开关控制；后续小毛驴前店需要界面按钮时，只需调用后厂接口即可对接。
