# OpenSpec 需求提案：老板商业诊断报告高转化视觉样式嵌入

> 需求发起方：产品负责人（师弟）  
> 架构设计方：全栈工程师 / GEO 架构师（师兄）  
> 视觉与样式真源：`/Users/zhouhaonan/Downloads/邻里GEO-AI可见度诊断报告（转化版）.html`  
> 目标页面：`https://geo.baicl.cc/#project=nextgeo&view=step-1-diag`

---

## 1. 为什么做（Why）

### 1.1 现状痛点
1. **管理端界面展示与下载排版脱节**：
   在管理后台 `view=step-1-diag` 页面中，【老板商业转化版】下方的预览框里，目前展示的是普普通通的 Markdown 纯文字排版（黑白文字 + 简单表格），视觉冲击力严重不足；
2. **高转化视觉大屏未能直接呈现**：
   系统虽然在昨天开发了自包含的 HTML 导出功能（浅紫色微流光 Hero、34 分醒目评分仪表盘、AIVO 四维雷达图、彩虹色谱卡片、真实问答证据表），但目前只能通过点击【下载老板商业报告 (HTML)】下载到本地后用浏览器打开，无法直接在管理后台界面里沉浸式预览；
3. **师弟核心诉求**：
   把这份更好看的转化版样式，直接放入管理端 `view=step-1-diag` 页面中；采用**方案 B**：顶层保持纯粹的两个大 Tab，在老板版的交付物预览卡片中增加“样式切换开关”，默认直接展示这份高颜值大屏，同时保留查看文本底稿的能力，两者内容完全一致。

---

## 2. 改动范围（What）

1. **管理端前端界面改造 (`web/index.html`)**：
   - **双样式无缝切换器**：在【老板商业转化版】交付物卡片头部，增加高质感的切换分段开关：
     - `高转化视觉版`（默认选中）
     - `文字底稿`（纯文字，供审阅润色）
   - **沙箱化嵌入容器**：新增独立隔离容器（通过 `iframe` 载入 `01_企业AI可见度商业诊断报告.html`），实现 100% 还原原生 SVG 图表、自适应宽度与浅紫微流光，同时坚决不污染管理端原有的 Tailwind CSS 与全局样式；
   - **全屏放大与外链预览**：在卡片操作栏补充【新窗口全屏预览】快捷图标，方便开会投屏或向客户当面演示。
2. **数据流与自动化联动**：
   - 当点击【直出商业诊断与焦虑转化初稿】后，前端在落盘 Markdown 的同时，立即刷新该高转化 HTML 容器，实现修改后秒级即时生效；
   - 保持 0 Emoji 严肃商业红线，内容与现存老板商业转化版 100% 严格对齐。

---

## 3. 对外能力（Capabilities）

- **能力 1（默认沉浸大屏）**：用户进入 `view=step-1-diag` 时，一眼就能看到与下载文件一模一样的高颜值浅紫流光视觉大屏。
- **能力 2（一键切换底稿）**：需要复制报告文字时，点「文字底稿」即可切回纯文字。
- **能力 3（零样式冲突安全保障）**：通过隔离沙箱展示，彻底避免任何全局 CSS 样式互相打架。

---

## 4. 影响分析（Impact）

- **受影响页面**：仅限管理端 `web/index.html` 中的 `view=step-1-diag` 阶段一区域。
- **工程师技术体检版**：完全独立，保持不变。
- **向后兼容性**：完全兼容现有的 API 接口和文件落盘路径（`01_企业AI可见度商业诊断报告.html` 与 `01_企业AI可见度商业诊断报告.md`）。
- **生产发布约束**：本地 `http://127.0.0.1:8088` 充分验证通过并经师弟验收前，绝对不擅自推生产。
