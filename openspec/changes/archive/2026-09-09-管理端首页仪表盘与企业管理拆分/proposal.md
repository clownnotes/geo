# Proposal: 管理端首页仪表盘与企业管理拆分

## Why (为什么做)

登录后的「项目管理大盘」把统计卡、巡检条、售前工具入口和客户大表揉在一页，主次不清；侧栏风琴与 `geo-*` 令牌只在进入单客户流水线后才出现，与上月「小毛驴式」管理端规范不一致。

产品已拍板：

1. **商业洞察独立一级菜单（方案 A）**——Pitch / EDI / 大盘 / 对标 / 矩阵 / ROI / 沙箱等单独逻辑，不堆首页。
2. **企业管理必须带搜索 + 筛选**。
3. **预留代理合作归属**：后续会与多名业务员/合作方共同拓客；每个企业可归在某位合作方名下，且可改挂；便于按人分类管理。

## What Changes (改动了什么)

1. **登录后全局壳**：与流水线同皮肤的 220px 侧栏 + 顶栏；不再用「无侧栏的一页大盘」。
2. **一级信息架构**（固定顺序）：
   - **仪表盘**（默认首页）：健康/巡检摘要 + 硬数字 + 可选「需关注」短列表；不含客户全表、不含售前工具堆砌。
   - **企业管理**：客户档案表 + 新建/批量/进流水线；**关键词搜索** + **筛选**（行业 / SOP 进度 / 告警相关 / **合作方归属**）。
   - **商业洞察**：售前与组合分析工具的独立入口页（卡片或列表跳转既有 Modal/能力）。
   - **运维告警**：全量巡检触发、告警与通知设置、规则说明（原首页 crontab/规则文案归此）。
   - **系统设置**：大模型中枢、离线导出（可从项目内设置提升为全局，或双向可达）。
3. **代理合作机制（本变更落地数据与筛选；不含业务员独立登录权限）**：
   - 维护合作方/业务员名册（可增删改）。
   - 每个客户项目绑定可选 `partner_id`（可空=直营/未分配）；支持改挂。
   - 企业管理按合作方筛选；仪表盘可展示「按合作方」摘要（可选，P1）。
4. **单客户流水线**：进入项目后仍用现有风琴菜单；「返回」改为回到 **企业管理**（或仪表盘），不再假装「返回一页大杂烩」。

## Capabilities (新增或修改的对外能力)

| 能力 | 说明 |
|------|------|
| 全局导航壳 | 登录后始终可见五大一级；视觉复用 `geo-admin.css` |
| 仪表盘页 | 只读聚合：项目数、交付完成、组合价值/ROI、巡检状态；可选异常摘要 |
| 企业管理页 | 表格 + 搜索（名称/ID/域名）+ 多维筛选 + CRUD 入口 |
| 商业洞察页 | 独立入口聚合既有商业 Modal，不改底层算法 |
| 运维告警页 | 巡检与通知配置从首页迁出 |
| 合作方名册 API | 列出/新增/重命名/停用合作方 |
| 项目归属字段 | 读/写 `partner_id`；列表与筛选带出合作方显示名 |

**非目标（本变更不做）**

- 业务员独立账号登录与数据隔离（二期权限模型）。
- 重写 Pitch/ROI/沙箱业务逻辑；仅改入口归属与壳层。
- 迁 Vue；继续单页 `web/index.html` + 现有 API。

## Impact (受影响的部分)

- `web/index.html`：拆分 `dashboard-view`；全局侧栏；新面板与筛选 UI。
- `web/geo-admin.css` / `docs/specs/geo-admin-ui-tokens.md`：必要时补仪表盘/筛选条组件类，禁止另起色板。
- `tools/geo/server.py`：项目列表返回 `partner_id`；合作方 CRUD；创建/更新项目支持归属。
- `projects/*/project.yaml`：新增可选 `partner_id`；存量缺省视为未分配。
- 新建配置：`config/geo_partners.yaml`（或等价路径）存合作方名册。
- 文档：可在 `docs/specs/` 补一页管理端 IA 说明（可选）。

## 验收标准（产品）

1. 登录默认落在 **仪表盘**，一屏能分清「健康 + 数字」，看不到客户全表。
2. 侧栏可进 **企业管理 / 商业洞察 / 运维告警 / 系统设置**；商业洞察内可打开原顶栏工具。
3. 企业管理：输入关键字能缩小列表；按行业、SOP 状态、合作方可筛选；可改某企业归属合作方。
4. 进入流水线后侧栏行为与现网一致；返回落在企业管理。
5. 无 Emoji；组件优先 `geo-*`。
