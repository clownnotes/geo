---

## 1. 痛点背景 (Why)

1. **老旧界面割裂**：目前系统中的「05 矩阵分发与链接检查」仍是老旧的单页滚动 DOM 结构，与前序已重构为 Vue3 3 竖列现代工作台的阶段（Step 0 摸底、Step 1 诊断、Step 2 官网、Step 3 母盘、Step 4 答题卡向量库）存在严重的视觉与交互断层。
2. **选题与答题卡脱节**：过去直接进入改写，缺少清晰的「选题任务库」。日常发文没有明确的“首篇打样”与“日常运营选题池”划分，无法记录哪些写过、哪些没写。
3. **分发缺乏闭环反馈**：虽然有外链回填，但文章发布后是否被下架（HTTP 404）没有与选题建立自动联动。一旦文章挂了，无法一键回溯并重新改写分发。
4. **严格遵循 SOP S7/S8**：需要将老赵哥《GEO项目全链路SOP》中的 S7（字典式结构、首段100字结论、模块独立无过渡词、十项质检）与 S8（头条/知乎主流渠道、外链回填台账、存活检测）完全产品化。

---

## 2. 改动内容 (What)

将现有的 `panel-step-4-distribute`（对应侧边栏 05 矩阵分发）全面升级重构为 **Vue 3 独立 3 竖列工作台组件岛（`Step5App.vue` / `GeoStep5Bridge`）**：

1. **左栏 · 选题任务库 (`TopicLibrary.vue`)**：
   - **AI 推荐预置选题**：根据阶段四答题卡自动生成首批推荐选题，并支持人工点击「+ 添加新选题」随时扩充选题库；
   - **双视图过滤**：一键切换「首次打样」（交付必做首篇）与「日常运营选题池」；
   - **状态标记**：直观展示 `待写作`、`写作中`、`已定稿`、`已上线存活`、`已失效/需改发`，做完可快速打勾标记。
   - **答题卡关联**：每个选题自动关联上一阶段匹配度最高的答题卡 ID（如 P01、V01 等），提供事实依据底牌。

2. **中栏 · 文章撰写与在线定稿编辑器 (`ArticleStudio.vue`)**：
   - **SOP 字典式结构生成**：基于选中的选题及其关联答题卡，一键生成符合 S7 规范的标准长文（搜索型标题 + 首段100字直接结论 + H2独立模块无过渡词 + 证据支撑 + 哲学金句）；
   - **在线实时精修**：所见即所得富文本/Markdown 编辑，支持随时修改微调品牌、联系方式与表述；
   - **自动质检与合规清单**：实时校验字数、敏感过渡词过滤、证据引用完整度、广告法红线；
   - **定稿秒级落盘**：核对确认后点击【保存定稿】，状态同步至选题库。

3. **右栏 · 矩阵分发、外链回填与 404 存活监测 (`DistributionMonitor.vue`)**：
   - **渠道分发卡片**：
     * **今日头条 / 豆包**（抓取必做）：一键复制适配富文本 + 直达头条号后台链接；
     * **知乎专栏 / DeepSeek**（技术加分）：一键复制长文富文本 + 直达知乎创作中心链接；
     * **拓展生态（折叠）**：微信公众号、百家号、小红书等；
   - **外链回填与存活监测**：
     * 发布后在对应渠道回填真实文章 URL；
     * 提供【一键检测链接存活】按钮；
     * **404 联动报警闭环**：若检测为 404（文章挂了），右栏显眼标红报警，左栏该选题自动变为【🔴 已失效/需改发】，并提供「一键改写重发」快速入口；若正常（200），标记为【🟢 已存活上线】。
