# Proposal: GEO 可视化 Web 管理端与 SOP 流水线系统

## Why (为什么做)

1. **权限与数据安全保密隔离（痛点一）**：
   - **非敏感信息**（如 GEO 白皮书、`/llms.txt`、公网优化文档、通用案例）需要完全公开在网页上，允许外部搜索引擎与大模型爬虫（Bytespider、Bingbot、Crawl4AI 等）自由抓取和索引。
   - **敏感商业信息**（如客户真实名称、合同预算、核心商业词库、私有技术资料、诊断扣分报告、周报归因数据）必须**严格保密**，必须通过账号密码鉴权后才能进入管理端访问。
2. **告别命令行的黑盒与沟通成本，实现全员可用（痛点二）**：
   - 目前的 CLI 命令行虽然功能完备，但对于非技术人员（销售、运营、项目交付人员）门槛较高。
   - 现有的对话式 AI 交互缺乏确定性与连贯性。需要一个**开箱即用的 Web 管理后台**，任何人输入账号密码登录后，界面清清楚楚，不需要摸索。
3. **标准化工业流水线作业（痛点三）**：
   - 将 GEO 交付的 5 个阶段（诊断 ➔ 底座 ➔ 重构 ➔ 分发 ➔ 监控）固化为**向导式（Step-by-Step Wizard）生产流水线**。
   - 任何员工只需在网页上点击“+新建项目”录入基础信息，点击“下一步”即可逐步调用底层程序完成生产，实现商业交付的标准化与规模化复制。

---

## What Changes (改动了什么)

1. **建设轻量级安全 Web 后端服务 (`tools/geo/server.py` / `web/server.py`)**：
   - 提供身份认证与会话管理（账号密码登录、Token/Cookie 鉴权、接口拦截）。
   - 封装 `tools/geo` 现有核心能力为 RESTful API（项目管理、5 步流水线触发、交付物读取与下载）。
   - 实现公私数据物理与路由隔离。
2. **构建现代化可视化前端管理控制台 (`web/static/` / `web/templates/`)**：
   - **登录鉴权页**：现代简洁的身份认证界面。
   - **客户项目总览中心**：项目列表、搜索过滤、完成进度卡片、“+新建项目”向导弹窗。
   - **5 步向导式 SOP 生产流水线工作台**：
     - `Step 1 现状诊断`：实时爬虫抓取体检、得分计算、在线 Markdown 诊断报告预览。
     - `Step 2 底座生成`：`llms.txt`、`JSON-LD`、`robots.txt` 代码高亮预览、一键复制与下载。
     - `Step 3 语料重构`：普林斯顿 9 因子结构化语料在线编辑、数据对比表格预览。
     - `Step 4 矩阵分发`：头条版、知乎版、GitHub 版卡片式分发展示、一键复制与发布标记。
     - `Step 5 监控周报`：SOV 品牌声量可视化图表大盘、关键词位次明细、一键导出客户周报。
3. **快捷启动入口与配置支持**：
   - 支持通过 `./geo web` 或 `python3 -m tools.geo web` 快速启动本地 Web 管理端。

## Capabilities (对外能力)

| 页面与功能模块 | 面向角色 | 核心能力说明 |
| :--- | :--- | :--- |
| **🔐 安全鉴权中心** | 管理员/员工 | 账号密码安全登录，拦截未授权访问，保护敏感商业项目资产 |
| **📁 客户项目看板** | 交付经理 | 集中管理多客户项目，一键新建客户、查看交付进度与健康分 |
| **🚀 5 步向导工作台** | 运营/执行人员 | 傻瓜式 SOP 流水线作业：“填写信息 ➔ 下一步 ➔ 下一步”，自动调用程序生成全套交付物 |
| **📄 交付资产导出中心** | 客户经理 | 在线实时预览所有 Markdown / 代码，支持一键复制代码或下载全套交付包 |

---

## Impact (受影响的部分)

- **新增 Web 模块**：`web/` 目录（前端 HTML/JS/CSS 静态资产与界面模板）及 `tools/geo/server.py`（Web API 后端）。
- **新增 CLI 指令**：`./geo web [--port 8080]` 快捷命令。
- **配置与安全**：新增管理员账号密码配置文件（支持环境变量或本地安全配置覆盖）。
- **文档更新**：在 `docs/` 中补充 Web 管理端使用说明。
