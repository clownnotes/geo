## 2. API Interface Design (后端接口规范)

所有私有接口需携带认证凭证（Session Cookie 或 `Authorization: Bearer <token>`），未授权统一返回 `401 Unauthorized`：

| 路由路径 | 请求方法 | 鉴权要求 | 接口职责与作用 |
| :--- | :---: | :---: | :--- |
| `/api/auth/login` | `POST` | 公开 | 管理员登录（入参: `username`, `password`），建立安全 Session |
| `/api/auth/logout` | `POST` | 需鉴权 | 登出并销毁 Session |
| `/api/auth/status` | `GET` | 公开 | 检查当前登录态及权限信息 |
| `/api/projects` | `GET` | 需鉴权 | 获取全部客户项目列表及完成状态与健康评分 |
| `/api/projects` | `POST` | 需鉴权 | 新建客户项目（入参: `client_id`, `name`, `url`, `keywords` 等） |
| `/api/projects/{id}` | `GET` | 需鉴权 | 获取指定项目的完整配置、原始材料清单与交付物状态 |
| `/api/projects/{id}` | `PUT` | 需鉴权 | 更新客户项目配置信息（修改词库、竞品等） |
| `/api/projects/{id}/run/{step}` | `POST` | 需鉴权 | 触发指定交付步骤（`audit`/`scaffold`/`rewrite`/`distribute`/`monitor`/`pipeline`） |
| `/api/projects/{id}/output/{filename}` | `GET` | 需鉴权 | 读取指定交付产物内容（返回 Markdown 或 JSON） |
| `/api/projects/{id}/export` | `GET` | 需鉴权 | 一键打包下载当前项目全部交付成果 |

## 3. Frontend UI/UX & SOP Flow (前端页面与向导设计)

前端基于现代化响应式单页架构构建（集成 Tailwind 视觉规范与 Markdown 实时渲染器），分为三大主视图：

### 3.1 视图 1：登录鉴权中心 (`#login-view`)
- 居中毛玻璃质感卡片，支持账号、密码输入与回车快速登录；
- 默认管理员账号：`admin`，密码：`geo2026!`（支持环境变量 `GEO_ADMIN_USER` / `GEO_ADMIN_PASS` 自定义覆盖）。

### 3.2 视图 2：客户项目大盘 (`#dashboard-view`)
- 顶部导航栏：品牌 Logo、当前操作员身份、安全退出按钮；
- 核心指标卡片：总项目数、已完成交付数、平均 SOV 声量提升率；
- 项目管理表格/卡片：支持关键字快速检索、一键点击“进入生产流水线”；
- “+ 新建客户项目”模态弹窗：表单式录入（项目ID、客户名称、官网 URL、所属行业、核心意图词、竞品）。

### 3.3 视图 3：5 步向导式 SOP 生产流水线 (`#wizard-view`)
- **顶部步骤条 (Step Bar)**：
  `① 现状诊断` ──► `② 底座改造` ──► `③ 权威重构` ──► `④ 矩阵分发` ──► `⑤ 声量监控`
- **步骤工作区 (Step Panels)**：
  - **Step 1 Panel**：点击【开始体检】按钮 ➔ 实时抓取目标站点 ➔ 展示 4 大技术合规标签与健康分 ➔ 在线阅读诊断报告 ➔ 点击【下一步】；
  - **Step 2 Panel**：点击【生成底座】➔ 标签页切换预览 `llms.txt` / `schema.jsonld` / `robots.txt` ➔ 支持一键复制与代码高亮 ➔ 点击【下一步】；
  - **Step 3 Panel**：左侧录入/编辑客户素材，点击【普林斯顿重构】➔ 右侧实时呈现结构化三元组、高精度参数对比表与搜索 Q&A ➔ 点击【下一步】；
  - **Step 4 Panel**：点击【导出分发包】➔ 卡片展示今日头条版、知乎专栏版、GitHub 版 ➔ 一键复制文案 ➔ 点击【下一步】；
  - **Step 5 Panel**：点击【执行声量监测】➔ 实时计算品牌 SOV 与排名 ➔ 渲染可视化仪表盘大盘 ➔ 点击【一键导出全套交付包】完成交付。
