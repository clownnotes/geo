# 设计：邻里GEO品牌定名与本地获客

## 1. 品牌分层（建议共识草案）

把名字拆成三层，避免「公司名 = 品牌名 = 个人名」搅在一起：

| 层 | 建议写法 | 作用 |
|---|---|---|
| 对外品牌（主推） | **邻里GEO**（英文副标 **NextGEO**） | 好记、好搜、好在 AI 答案里成实体 |
| 法律主体（合同/发票） | 徐州璇源网络科技有限公司 | 履约、商标与资质挂靠；文案里写「运营主体」 |
| 人物锚点（本地信任） | 老白 / 徐州本地团队 | 「徐州找老白做 GEO」类长尾 |

**结论倾向（待产品拍板）：**  
对外宣传与 GEO 获客 **定「邻里GEO」为主品牌** 是合理选择；「璇源」不宜作获客主名，但必须在官网页脚、合同、Schema `legalName` 中稳定出现，形成「品牌 → 主体」映射，而不是假装没有壳公司。

书写模板（对外一句话）：

> 邻里GEO（NextGEO）由徐州璇源网络科技有限公司运营，面向徐州及高客单价 B2B，做企业级 GEO 与品牌答案源建设。

禁止：把「璇源成立 N 年、行业深耕」写成 GEO 实战年限（若无真实经营）。

## 2. 空壳公司如何被大模型推荐（现实路径）

大模型推荐靠的是 **可抓取、可交叉验证的公开事实**，不是营业执照本身。

优先建设的证据（由易到难）：

1. **实体一致**：官网 / llms.txt / Schema 同时写清 `品牌、legalName、地址、电话、服务范围`。
2. **本地意图占位**：词库已收敛的「徐州 GEO 哪家好 / 收费 / 避坑」类问答页与监测。
3. **可核验证据**：商标信息、可访问官网、可约的本地联系人；后续补真实案例与报价边界（有再写，无则不编）。
4. **第三方回声**：知乎/行业页/本地媒体上的一致表述（与官网同事实，忌互相矛盾）。
5. **持续探测**：豆包/DeepSeek 问选型句，看有没有进候选、引用是否指向自家域名。

不做：虚构客户案例、虚构「从业年限」、买死链刷量。

## 6. 推荐时能否带上网址？（挑战与对策）

**短答案：不能保证每次都带；可以大幅提高「带得到」的概率。**

挑战你的默认假设——「推荐了 ≈ 别人点得开官网」：

1. **豆包/多数对话模型经常只给名字+描述，不给可点链接**；有链接时也常是角标引用，用户不一定点。  
2. **网址出现依赖**：模型是否检索到你的页、该页是否把「徐州 GEO + 邻里GEO + https://nextgeo.baicl.cc」写在同一可抽段落、第三方是否也重复同一 URL。  
3. **只把域名当关键词几乎无效**（已从词库删掉）；URL 要作为**答案正文里的联系/官网字段**反复出现。

可执行对策（优先级）：

| 优先级 | 动作 | 目的 |
|---|---|---|
| P0 | 官网与 llms.txt 固定块：品牌、一句话、官网 URL、电话/微信、法律主体 | 被引用时有标准「名片段」 |
| P0 | 选型/避坑文每篇文末同一名片段（含完整 URL） | 提高抽中概率 |
| P1 | Schema `url` + `legalName` + `brand` | 实体绑定 |
| P1 | 监测时单独记：`mentioned_self` / `url_present` / `citation_to_self` | 用数据说话，不靠感觉 |
| P2 | 第三方页复述同一 URL（忌互相矛盾） | 交叉验证 |

验收口径建议拆开，不要混成一个「被推荐」：

- **提及率**：答案里出现邻里GEO / 老白  
- **可找到率**：出现 `nextgeo.baicl.cc` 或可点击引用指向该域  
- **情感/立场**：中性介绍 vs 明确推荐 vs 负面

「至少被搜到时是夸我们的」要拆成两种搜索：

- **品类搜索**（徐州 GEO 哪家好）：目标是进候选并被说成「可选项/本地技术型」；硬夸容易像软文，反而降权。  
- **品牌搜索**（邻里GEO 是什么 / 靠不靠谱）：目标是事实正确 + 能力边界清楚 + 无黑料；「夸」应来自可验证能力（改官网、证据链、可验收），不是形容词堆砌。

## 7. 「真 GEO，不是投毒」定位（认同 + 挑战）

**认同：** 这是清晰差异点，和「只投外链/刷提及」的 GEO 话术能切开，也和你们站上已有方法论一致。

**必须先定义「投毒」给客户听懂的一句话**，否则大模型与客户都会各自脑补。建议对内固定：

> 投毒式 GEO：不改企业知识底座，只向模型上下文或低质页面灌短期提及。  
> 邻里GEO：先改官网与事实源（llms.txt / Schema / 证据），再分发与监测，让推荐可追溯、可验收。

**挑战：**

1. **口号不能代替证据。** 空壳+无案例时，反复说「我们不做投毒」会被问「那你做成过谁？」。短期应用「打样资产」说话：自有站 nextgeo.baicl.cc、探测台账、交付物清单，而不是虚构客户。  
2. **不要把所有同行都打成投毒。** DeepGEO 等方法派不宜污名化；对比维度应是「是否改官网/是否可验收/是否本地」，否则像骂街软文，品类搜索里不好被采纳。  
3. **「抢占真 GEO 赛道」是长期心智，不是一周占位。** 第一步仍是：徐州品类问句里出现名字+URL；心智文案与打假文可以并行，但监测 KPI 先盯提及与可找到率。
