# GEO 诊断报告 · 转化导向结构大纲（可复用模板）

> 用途：免费给客户、用于引流转化的 GEO 诊断报告，统一按此结构出。
> 核心逻辑：把「审计流程」顺序，改成「客户心理旅程」顺序——
> **注意 → 痛点 → 安抚 → 痛点放大 → 路径 → 愿景 → 行动**。
> 小标题用「客户利益视角」，不用「审计功能视角」。

## 一、结构大纲（带每节转化作用）

```
标题（Hook）
└ 一句话戳痛点，不用客户名也能看懂的处境反差
└ 评分徽章：🟢 XX/100（评级）｜ 技术分由真抓生成，禁止改写

① 一页结论（老板速读版）                —— 注意 + 痛点（30 秒抓住老板）
   ├ AI 可见度四维评分卡（🟢🟡🔴 + 真源依据）
   ├ 综合探针（提及率 / 带官网率 / 幻觉风险率）
   ├ 三个状态卡（技术 / 可引用性 / 可见度）
   ├ 你正在流失的 N 类询盘（钱/线索的具体流失）
   └ 三个必须正视的业务缺口（缺口→商业含义）

② 好消息：你的[技术/资产]其实很能打       —— 安抚（降低防御，证明不用推倒重来）
   ├ 体检明细表（维度/检测值/规范/结论/扣分）
   ├ 关键问题（唯一硬伤）
   └ 市场定位诊断一句话（有X、无Y 的早期洼地）

③ 坏消息：AI 现在根本认不出你的品牌       —— 痛点放大（丢单主引擎）
   ├ N 条问句可见度对照表（是否提及/官网/立场/竞品）
   ├ 竞品占位透视（谁在吃你的入口 + 它凭什么占位）
   └ 认知风险一句话（最易被误读成什么）

④ 四步破局路线：从「能被读到」到「被推荐」—— 路径 + 希望
   ├ 步骤总览（优先级 P0/P1 + 周期 + 一句话目标）
   ├ 第一步 [品牌标准答案卡]（P0）
   ├ 第二步 [正文密度补到可引用]（P0）
   ├ 第三步 [按问句补证据链]（P1）
   └ 第四步 [固定复测]（含多平台扩展说明）

⑤ 30 天后，你能拿到什么                  —— 愿景具象化（现在 vs 目标 对比表）

⑥ 下一步：把这份免费体检变成真实询盘      —— 行动（CTA）
   └ 软广（最低档价仅提一次）+ 联系占位

Footer：评测元信息（折叠，数据真源）
```

## 二、每节填充要点 + 数据来源

| 节 | 转化作用 | 必填内容 | 数据来源 |
|---|---|---|---|
| 标题/Hook | 让客户秒懂"这说的是我" | 一句处境反差（如"你帮客户做X，但AI搜你却不认识"） | 客户业务 + 诊断结论 |

## 四、从 HTML 版借鉴的 5 个结构优点（已并入上文）

1. **AIVO 四维评分卡**：把总分拆成维度（基建/内容/可见度/竞品/舆情），🟢🟡🔴 一眼看分布。
2. **综合提及率统计**：提及率 / 带官网率 / 幻觉风险率，用率值制造紧迫感。
3. **竞品深度档案（占位透视）**：不只列竞品名，还写"它凭什么占位 = 你的缺口镜像"。
4. **品牌优势/劣势 + 市场定位一句话**：收口一个定位判断，方便客户记住自己。
5. **多平台复测说明**：单平台达标不算赢，扩到 8 大 AI 平台做"全平台提及率"看板。

> ⚠️ 注意：以上"优点"是**结构框架**，不是数据。套用时务必填入**本次真抓的真实值**；
> 切勿直接套用其他客户/模板里的分数、竞品分、主体——会识别错主体、掉信任。
