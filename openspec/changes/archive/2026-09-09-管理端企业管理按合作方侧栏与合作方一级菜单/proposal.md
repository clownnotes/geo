# Proposal: 管理端企业管理按合作方侧栏与合作方一级菜单

## Why (为什么做)

上一版把「企业管理」「合作方名册」都塞在「工作台」平铺二级，或埋进「系统设置」Tab。实际高频动作是：

1. **按某个代理渠道看名下企业**——应像文件夹一样点侧栏分类，而不是先进企业管理再翻筛选框。
2. **维护合作方名册**——常用，不应藏在系统设置里；且后续还要加渠道相关能力，需要独立一级留扩展位。

产品意向：企业管理单独一级；其下二级按各代理渠道下拉；合作方管理也单独一级。

## What Changes (改动了什么)

### 侧栏信息架构（登录后全局壳）

| 一级（风琴） | 二级 | 说明 |
|--------------|------|------|
| **工作台** | 仪表盘、商业洞察、运维告警、系统设置 | 系统设置**不再含**合作方名册 Tab（仅大模型 / 导出说明） |
| **企业管理** | **全部企业**、**未分配**、以及每个 `status=active` 的合作方名称 | 点击某合作方 → 打开企业管理页并**预置该合作方筛选**；点击「全部企业」清空合作方筛选 |
| **合作方管理** | 本期仅 **合作方名册** 一页（CRUD/归档，从设置迁出） | **不放空二级占位**；渠道绩效等二期再加二级 |

### 企业管理页

- 保留表内搜索、行业/SOP 筛选与行内改挂。
- 侧栏点合作方时，与顶栏「合作方」下拉**双向同步**（改下拉也高亮对应侧栏项）。
- 合作方增删改/归档后，**企业管理风琴二级列表即时刷新**。

### 非目标

- 不做业务员独立登录与数据隔离（仍属二期）。
- 不改交付流水线内项目侧栏。
- 不新造第三套 UI 色板；继续 `geo-admin.css`。

## Capabilities (新增或修改的对外能力)

- 侧栏动态渲染 active 合作方为「企业管理」二级菜单。
- 带筛选进入企业管理统一走专用入口 `openEnterprisesByPartner(partnerId)`；**不改** `switchHomeView(viewId, skipRoute)` 的既有第二参语义（现网 `skipRoute` 为布尔，勿塞对象）。
- 独立视图 `home-partners`（合作方管理），迁出原 settings 内名册 UI。
- （可选）URL/hash 带 `partner=` 便于刷新保持。

## Impact (受影响的部分)

- `web/index.html`：`#home-sidebar` 结构、`switchHomeView`、合作方列表渲染、settings Tab。
- `web/geo-admin.css`：必要时微调风琴内动态项样式（无新色板）。
- 后端 API 可复用现有 `/api/partners`；一般无需改契约。
- OpenSpec 归档变更「首页仪表盘与企业管理拆分」之上的增量 IA。

## 验收标准

1. 「企业管理」是独立一级风琴，展开可见全部企业 / 未分配 / 各合作方。
2. 点某合作方只看到该方企业；点未分配只看未挂靠；与顶栏筛选一致。
3. 「合作方管理」为独立一级，可完成增改归档；系统设置里不再有合作方名册。
4. 无 Emoji；常用路径不超过两次点击到达「某渠道下的企业列表」。
