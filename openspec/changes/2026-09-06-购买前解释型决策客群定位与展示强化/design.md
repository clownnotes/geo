# Design: 购买前解释型决策客群定位与展示强化

## 1. 架构与视觉设计

### 1.1 官网首页 (`docs/index.md`) Bento Grid 组件设计
- **响应式 CSS 架构**：采用 VitePress 原生样式兼容的 HTML/CSS 网格布局（支持浅色/深色主题无缝切换）。
- **结构拆解**：
  - **Banner 导语**：突出“为什么这类企业不做 GEO 就会失去第一轮客户？”
  - **Bento 核心大卡片（左侧）**：深蓝/暗黑高质感背景、醒目微标签、超大粗体“购买前有大量解释型问题”、副标“用户在成交前越需要大量对比与解释细节，AI 搜索的第一轮推荐越直接决定生死”。
  - **行业卡片（右侧 6 宫格）**：
    1. **B2B SaaS / 数字化软件**：功能、价格、集成、安全与迁移成本解释。
    2. **工业制造 / 机械装备**：参数公差、材料认证、应用场景与定制交付。
    3. **企业服务 / 技术工作室**：交付流程、团队经验、源码归属与质保边界。
    4. **高客单价商业产品 / 加盟**：多轮横向比较、投资回报量化与风险确认。
    5. **专业咨询 / 财税法务**：方法论、行业判例、合规流程与权威信任。
    6. **职业教育 / 高端培训**：课程体系、实操认证、真实就业去向验证。
  - **真问法对比表格**：直观列出“适合行业”、“采购前真实高频问法”、“为什么必须做 GEO（大模型推荐机制）”。

### 1.2 商业白皮书 (`docs/strategy/pricing-and-industry-playbook.md`) 理论升华
- 引入**“解释型决策指数 (Explanatory Decision Index, EDI)”**概念。
- 对比冲动快消品 vs 复杂解释型产品的 AI 采纳分流。
- 阐明为什么“普林斯顿 9 因子（数据注入 +37%、对比表格、权威引用）”正是为了回答“解释型问题”而生的最佳解法。

### 1.3 交付工作台 (`web/index.html`) 诊断弹窗
- 在工作台顶栏新增 `🎯 适合客群 (EDI)` 快捷按钮。
- 打开专属 Modal，支持查看 6 大典型客群、问法拦截模拟器与解释度自测。
