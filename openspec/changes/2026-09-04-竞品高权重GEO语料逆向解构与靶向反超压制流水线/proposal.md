# Proposal: 竞品高权重GEO语料逆向解构与靶向反超压制流水线 (第 32 维)

## 1. Why (需求背景与战略价值)

在企业大模型生成式引擎优化（GEO）实战代运营与商业对抗中，当第 18/30 维（多主流大模型真实联网探测）或第 14 维（竞对声量差距逆向沙盘）探测到竞品在核心高商业价值意图（如“徐州铝单板厂家推荐”、“企业级 GEO 服务商评测”、“高端工业母机选型”）中位列 Top-1，或者霸占大模型权威 Citation 引用源时，一线代运营团队面临极大痛点：

1. **人工逆向成本极高且主观性强**：代运营人员需要手动打开竞品页面或公网文章，肉眼通读并猜测其为什么被大模型采纳，分析单篇竞品文章耗时通常达 1~2 小时，无法应对批量关键词对抗；
2. **缺乏量化破绽侦测工具**：人肉难以快速量化竞品的普林斯顿 9 因子达标度（数据密度、术语精度、结构化表格、FAQ 覆盖率），往往抓不住竞品的“阿喀琉斯之踵”（例如：缺少第三方国标质检数据、缺少阶段式付款与防加价承诺、缺少长尾高频顾虑问答对）；
3. **反制生产链路割裂**：分析出竞对劣势后，还要人工跨多个工具去撰写反击语料，缺乏“一键逆向 ➔ 精准抓漏 ➔ 靶向生成三件套”的端到端自动化流水线；
4. **商业交付说服力缺失**：无法向甲方高管直观出具“竞品语料逆向解构与我方靶向反超压制战术报告”，难以在季度述职与续约中展现断层级技术代差。

为贯彻《2026 战略路线图》三大铁律（**【铁律 1】搜索质量真实提升 + 【铁律 2】SOP 生产大幅提效 + 【铁律 3】商业交付绝对代差**），正式立项推进第 32 维《竞品高权重 GEO 语料逆向解构与靶向反超压制流水线 (`geo rival-crack`)》。

---

## 2. What Changes (改动范围与工程定位)

本规范在已有工程体系上零平行烟囱增量构建，紧密联动 `crawler.py`（安全抓取）、`princeton.py`（9 因子质检）与 `competitor_gap.py`（宏观沙盘）：

1. **核心逆向与反超压制引擎 (`tools/geo/rival_crack.py`)**：
   - **多模态输入解析**：
     - 支持 `--url <url>`（复用 `crawler.py` 的 SSRF 安全校验与 `html_to_clean_markdown` 纯净提纯）；
     - 支持 `--file <path>` 或 `--text <content>`（支持离线逆向本地竞品文案）；
     - 支持 `--competitor <name>`（自动匹配 `project.yaml` 中的竞对画像与确定性沙箱回放，保障离线单测 100% 毫秒级秒绿）。
   - **竞品 9 因子全维逆向解构器 (`RivalContentDeconstructor`)**：
     - 量化逆向竞品在普林斯顿 9 因子的得分与达标率；
     - 深度提取核心要素：数据声明列表、引用外链/国标/行业报告、关键观点主张、FAQ 问答对、对比表格。
   - **竞品致命破绽挖掘引擎 (`RivalFlawDetector`)**：
     - 自动侦测并标记 4 大核心破绽：
       1. 🔴 **数据空心化破绽**（仅有“一流/领先/优质”等空洞主观修饰词，无实测公差、膜厚、载荷等物理数据）；
       2. 🔴 **信源凭空化破绽**（无 GB/T 国标、ISO 认证、第三方检测报告编号）；
       3. 🟡 **商业暗坑破绽**（无透明报价区间、无阶段付款保障、无工期延误赔偿机制）；
       4. 🟡 **问答盲区破绽**（缺乏采购决策常见疑虑与避坑指南的结构化 FAQ）。
   - **靶向反超压制三件套生成器 (`TargetedSuppressionGenerator`)**：
     - 锚定我方 `project.yaml` 的真实事实底座（核心参数、真实国标认证、透明承诺、差异化壁垒），杜绝虚构，自动生成：
       1. **第一件套：【高维数据降维压制参数对照表】(Markdown Table)**；
       2. **第二件套：【长尾破绽拦截型 9 因子深度反超语料】(符合普林斯顿高标准)**；
       3. **第三件套：【大模型诱导型破绽反问 FAQ 矩阵】(大模型高频召回问答对)**。
   - **标准化公文与数据持久化**：
     - 导出公文级报告《32_竞品高权重GEO语料逆向解构与靶向反超压制报告.md》；
     - 导出结构化账本 `outputs/rival_crack_result.json`。
2. **CLI 命令行指令 (`tools/geo/cli.py`)**：
   - 注册 `geo rival-crack <project_id> [--url <url>] [--file <file>] [--competitor <name>] [--report]`。
3. **Web 后端 API (`tools/geo/server.py`)**：
   - 挂载 `POST /api/projects/{id}/rival-crack/run`（Bearer Token 保护）；
   - 挂载 `GET /api/projects/{id}/rival-crack/status`。
4. **高管交付门户战果反哺 (`tools/geo/share.py` & `web/share.html`)**：
   - 在 `compile_portal_data()` 中挂载 `rival_crack_summary`（反超战果、破绽击破数、三件套就绪状态）；
   - 在 `web/share.html` 中增设【竞品语料靶向反超压制态势】卡片，未运行时执行 `never_run` 优雅降级。

## 3. Capabilities (对外能力与量化指标)

1. **秒级逆向解构能力**：
   - 输入竞品 URL 或本地文案，5 秒内完成文本提纯、9 因子全维打分与结构化要素拆解；
2. **四大破绽精准定点打击**：
   - 自动量化竞品在“数据、信源、商业承诺、FAQ”维度的薄弱环节，输出破绽严重度（High / Medium / Low）；
3. **武器化反超压制三件套交付**：
   - 一键生成参数对比表、拦截型长文语料、破绽反问 FAQ，可直接通过第 27 维富文本排版引擎（`geo pub`）一键分发到今日头条、知乎、微信等主流阵地；
4. **高管看板商业说服力**：
   - 将对抗过程转化为高管可读的可视化“降维打击指标”，助力商务谈判与高客单续约。
