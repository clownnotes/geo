# Design: 微信搜一搜与腾讯元宝一键排版助手与私域引流打包器

## 1. 微信原生富文本 HTML 编译架构 (`tools/geo/publisher.py`)

微信公众平台编辑器过滤一切 `<style>` 标签与外部样式表，所有排版必须依赖 **100% 纯内联 Inline CSS (style="...")**：

```
9 因子精修语料 (03_普林斯顿*.md / project.yaml)
                     │
                     ▼
       微信内联 HTML 编译器 (build_wechat_article_html)
       ├── 1. 顶部：微信绿 (#07c160) 渐变导读与官方认证标识卡片
       ├── 2. 章节：圆角带左侧 4px 粗边框的小标题
       ├── 3. 数据：自适应细边框斑马纹表格 (border-collapse: collapse)
       ├── 4. 引用：带浅绿底色与大引号的普林斯顿金句引用块
       ├── 5. 底部：专属【创始人名片 + 微信直营咨询卡片 + 防伪认证】
                     │
                     ▼
  一键输出 outputs/wechat_pack/
  ├── 01_微信公众号原生内联排版长文.html  (可全选直接粘贴至公众号后台)
  ├── 02_微信视频号60秒口播脚本与分镜表.md (含 3 组爆款封面与分镜描述)
  └── 03_微信搜一搜关键词配置与发稿SOP.txt (话题 Tag 与发布自检项)
```

## 3. CLI 与 Web 服务端接口

- **CLI 指令**：`geo publish <project_id> --channel wechat`
- **Web 端 API**：
  - `GET /api/projects/{id}/wechat/preview`：返回富文本 HTML 与剪贴板 Payload；
  - `GET /api/projects/{id}/wechat/video`：返回视频号脚本；
  - `POST /api/projects/{id}/wechat/build`：重新生成并打包。
