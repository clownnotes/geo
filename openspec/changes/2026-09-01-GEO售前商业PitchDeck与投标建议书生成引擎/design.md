## 3. RESTful API 契约

### ① `GET /api/projects/{id}/pitch/data`
- **Response**: 返回建议书结构化 Markdown、10 页幻灯片大纲数据与 3 档报价对比。

### ② `GET /api/projects/{id}/pitch/slides`
- **Response**: 返回深色科技风的交互式全屏幻灯片 HTML（支持左右方向键切换、触摸滑动与全屏放映）。

### ③ `GET /api/projects/{id}/pitch/print`
- **Response**: 返回标准 A4 纸排版的商业建议书 HTML，支持直接 Ctrl+P 打印或另存为 PDF 标书。
