## 3. 后端数据结构与周报更新逻辑

1. **解析器抽象 (`parse_probe_text`)**：
   - 提取自现有的 `probe_llm_live` 中的正文与位次解析逻辑，输入 `content, client_name, brand_name, competitors`，输出统一结果对象；
   - 增强 Citation 提取能力：不仅支持常规 `http(s)://`，也兼容大模型返回的常见脚注引用（如 `[1] 知乎专栏...`、`[2] 今日头条...`）。

2. **周报明细行更新机制**：
   - 若《`05_企业AI可见度与声量追踪周报.md`》不存在，先以项目初始配置生成标准周报骨架；
   - 在「二、关键词逐项探测明细表」中匹配 `keyword + model`：
     - 若已存在旧行，将其替换为新的实测结果，并在模型列标记为 `DEEPSEEK (真机实测)`；
     - 若不存在，追加新行；
   - 重新统计 SOV、Top3、Citations 权威分布并同步重写周报头部大盘；
   - 将实测记录持久化保存至 `outputs/05_manual_probes.json`，确保项目重启或重新生成周报时真机数据不丢失。

## 4. 前端交互设计规范 (UI/UX)

1. **视觉规范**：
   - 严禁滥用彩色 Emoji 表情（遵守 AGENTS.md 规范）；
   - 使用 Lucide 图标（`copy`、`external-link`、`check-circle`、`file-text`、`sparkles`）；
   - 采用深色/浅色高对比微边框与 Tag 标签展现状态。
2. **操作便捷性**：
   - 点击“复制”按钮后即时变为“已复制”（持续 1.5s），无需切换窗口打字；
   - 平台链接添加 `target="_blank"` 并在气泡中提醒“建议右键使用无痕窗口打开”；
   - 回填输入框提供“清空”与“示例填充”辅助按钮，方便快速测试。
