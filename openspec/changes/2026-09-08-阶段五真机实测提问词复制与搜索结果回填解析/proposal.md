# Proposal: 阶段五真机实测提问词复制与搜索结果回填解析

## Why (为什么做)

1. **解决普通 API 不联网的滞后盲区**：
   - 现有的阶段五「执行实时声量检测」主要依赖后端调用大模型 API（`probe_llm_live`）。但标准大模型 API 默认走预训练静态底座，无法实时检索最新抓取的互联网网页（如知乎、头条新发文章）。
   - 这导致运营人员在阶段四刚分发完矩阵文章后，若立即跑 API 探测，可能无法测出最新上榜的实时增量效果。

2. **消除大模型 API Key 配置门槛与成本**：
   - 很多用户或现场交付工程师在演示或未申请商业 API Key 时，系统只能走“离线基准测算”，缺少真实的交互数据；
   - 支持无痕实测回填，能够让用户在零 API 成本、零配置的前提下，获取 100% 真实的线上效果验证。

3. **满足商业交付中最有说服力的“真机无痕实测”需求（Ground Truth）**：
   - 在企业级高客单客户验收结案时，客户最认可的不是后台的 API 跑分，而是当面打开无痕浏览器、在 DeepSeek / 豆包输入采购选型词，亲眼看到品牌排在第一位并引用了官方文章；
   - 现有系统缺少“提问词一键复制”和“网页端完整结果回填解析”的标准闭环，无法将真机实测的客观数据自动化沉淀进验收单与商业 ROI 看板。

---

## What Changes (改动了什么)

1. **阶段五新增「真机无痕实测助手」交互组件**：
   - 在阶段五顶部控制栏增加「真机实测与回填」入口；
   - **拟真采购提问词一键复制**：针对项目配置的核心商业意图词，自动生成适配 DeepSeek、豆包、腾讯元宝、Kimi 的拟真采购决策者提问词，并附带直达官网链接与“无痕模式”操作指引；
   - **网页回答粘贴与实时解析**：提供富文本/纯文本回填抽屉，支持将浏览器中复制的大模型完整回答（包含正文推荐与末尾 Citations 外链）一键粘贴回填。

2. **后端新增真机数据提取与合并引擎**：
   - 抽象大模型回答通用语义提取器，解析出：**品牌提及位次（Rank）、Top 1/Top 3 达成情况、竞品拦截、外链 Citation 域名加权渗透**；
   - 将真机实测（Ground Truth）数据合并入《`05_企业AI可见度与声量追踪周报.md`》，并在周报中清晰标记 `[真机无痕实测]` 信源来源，与 API 探测数据兼容互补。

3. **大盘指标与商业 ROI 实时联动**：
   - 回填并解析成功后，即时触发前端 4 维核心指标卡（SOV、DeepSeek首推率、豆包首推率、权威信源评分）与商业 ROI 价值折算看板的动态刷新。

---

## Capabilities (新增或修改的对外能力)

1. **`GET /api/projects/{id}/monitor/prompts`**：
   - 获取项目核心词的各平台拟真提问词、平台直达 URL 与无痕测试建议。
2. **`POST /api/projects/{id}/monitor/manual-ingest`**：
   - 接收用户从网页端复制的真实回答内容，自动执行位次解析、竞品判定与 Citation 提取，更新周报与指标大盘，返回解析报告。
3. **前端「真机实测回填」弹窗**：
   - 提供“选词复制 -> 打开平台 -> 贴回解析 -> 刷新大盘”的极简 4 步交付工作流。

---

## Impact (受影响的部分)

* **后端服务**：`tools/geo/monitor.py`（提取解析公共函数、合并真机记录入周报）、`tools/geo/server.py`（新增 prompts 与 manual-ingest 两个 REST 路由）。
* **前端界面**：`web/index.html`（阶段五控制栏增加入口、新增真机实测回填弹窗、联动大盘与 ROI 刷新）。
* **交付物料**：周报《`05_企业AI可见度与声量追踪周报.md`》增加真机实测标注与明细条目。
