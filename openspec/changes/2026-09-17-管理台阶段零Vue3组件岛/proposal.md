# Proposal: 管理台阶段零 Vue3 组件岛

## Why (为什么做)

- 管理台几乎整站塞在 `web/index.html`（约 1.6 万行）。改阶段零时易出现「HTML 架子有了、渲染 JS 没装上」→ 界面永远「清单加载中」，被误判成「数据又丢了」。
- 业务还在高频改阶段零（问题清单列表/预览/删除、豆包答案回填、提示词）。继续在大单页里改，同类事故会反复。
- 小毛驴前端已用 Vue3 组件化；GEO 应学**组件边界**，用绞杀式迁移，而不是等全站写完再拆、也不是一次翻成整仓 SPA。

## What Changes (改动了什么)

- **只拆阶段零（步骤 00）**：从 `web/index.html` 抽出为 Vue3「组件岛」，挂在原有管理台壳子里的一个挂载点。
- **其余步骤暂不动**：诊断 / 母盘 / 分发等继续用现有 HTML+脚本，后续谁常改谁再拆。
- **行为对齐已归档共识**：问题清单 ≠ 豆包答案存档；B 区列表/时间/预览/删除；文案走 plain-speak（五年级能懂）；数据仍落 `projects/{id}/outputs/probe_script_*.json` 与 `competitor_probe_*.json`。
- **工程护栏**：构建产物可测；缺列表渲染能力时不得静默卡在「加载中」；加载失败写人话错误。

## Capabilities (新增或修改的对外能力)

- 阶段零 UI 以 Vue3 组件维护；开发改文件路径清晰（列表 / 预览 / 复制提示词等可定位）。
- 对用户：阶段零操作路径不变（Safari 管理台 `127.0.0.1:8088`）；不要求用户学新工具。
- 对外 API：原则上复用现有 `/api/projects/...` 探活相关接口；本变更不改探活业务契约，除非 tasks 显式列出。

## Impact (受影响的部分)

| 影响面 | 说明 |
| :--- | :--- |
| `web/` | 新增 Vue3 源码与构建产物；`index.html` 阶段零区块改为挂载点 |
| 管理台静态托管 | 需能提供 `web/dist` 或等价静态资源（见 design） |
| 后端探活 API | 默认只读复用；不改磁盘文件命名约定 |
| 文档 | 仅 OpenSpec 本目录为共识真源；不新建 `docs/specs` 旁路 |
| 非目标 | 全站 Vue 化、换路由框架、改小毛驴密钥入口、推生产自动部署 |

## 产品拍板（已对齐探讨）

- **时机**：先组件化最痛的一块，再继续改功能（不要「全写完再拆」）。
- **范围**：阶段零小岛，不是全站重写。
- **前序变更**：`2026-09-16-创建与阶段零先探活再长问选题` 已归档；Safari 细测可后续补，不挡本变更开干。
