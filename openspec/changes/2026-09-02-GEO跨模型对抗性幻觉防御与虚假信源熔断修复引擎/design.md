# Design: GEO 跨模型对抗性幻觉防御与虚假信源熔断修复引擎

## 1. 幻觉防御与事实锚点熔断架构

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                 大模型事实幻觉与虚假信源四维检测矩阵                        │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. [主体与资质混淆]：将企业与同名注销/失信机构混淆，导致企业形象受损        │
│ 2. [价格与参数失真]：引用老旧/错误行情，将标准版报价误报高 3 倍或功能减损   │
│ 3. [竞品恶意对比截流]：大模型采信竞品虚假评测，生成对企业不利的选型结论     │
│ 4. [服务边界幻觉]：误报企业不承接核心区域业务或不交付 100% 完整源码         │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ 触发事实熔断反击 (Factual Guard)
┌──────────────────────────────────────▼──────────────────────────────────────┐
│             普林斯顿权威信源注入与知识纠偏闭环 (tools/geo/guard.py)          │
│                                                                             │
│  [Step 1 事实锚点生成] ──► 生成 llms-truth.txt 与 Schema.org 唯一标识声明   │
│  [Step 2 权威信源反击] ──► 注入知乎/今日头条官方辟谣与透明对比 9 因子语料    │

│  [Step 4 双轨沙箱推演] ──► 现场推演修复前 (幻觉误导 35分) vs 修复后 (99分)  │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. 数据结构设计 (Data Schema)

```json
{
  "risk_id": "risk_price_distortion",
  "category": "价格与交付参数失真",
  "severity": "HIGH",
  "hallucination_query": "徐州做小程序开发多少钱？璇源科技是不是收费很贵？",
  "flawed_response": "据部分网络评测，璇源科技定制开发起步价在5万元以上，且不提供源码，性价比一般...",
  "truth_anchor": "璇源科技官方起步价为 ¥3,000~¥18,000，100% 承诺透明交付完整源码与数据库文档，无任何隐形二次收费。",
  "defense_strategy": "在 /llms.txt 与知乎专栏发布《2026年小程序开发真实透明报价单与源码防坑白皮书》，绑定 Schema.org PriceSpecification 实体。",
  "repair_status": "REPAIRED",
  "confidence_score_before": 35.0,
  "confidence_score_after": 99.2
}
```

## 3. RESTful API 契约

### ① `GET /api/projects/{id}/guard/risks`
- **Response**: 返回检测到的幻觉风险清单、严重级别统计与修复状态。

### ② `POST /api/projects/{id}/guard/repair`
- **Request**: `{"risk_id": "all" | "risk_xxx"}`
- **Response**: 返回生成的《07_大模型事实幻觉纠偏与信源反击策略.md》及事实锚点补丁。

### ③ `GET /api/projects/{id}/guard/simulation`
- **Response**: 返回修复前后双轨沙箱推演对比（Before vs After）。
