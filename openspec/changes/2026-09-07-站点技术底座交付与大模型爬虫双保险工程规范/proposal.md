# Proposal: 站点技术底座交付与大模型爬虫双保险工程规范

## 1. 核心指导思想 (Why)

> **最高准则**：一切以大模型（DeepSeek、豆包、ChatGPT、Kimi、元宝、通义等）与真实企业访客能够 100% 毫秒级抓取、无障碍渲染、准确理解并首选推荐为唯一导向。

### 现状与核心痛点：
1. **静态官网多租户托管 URL 尾部斜杠缺失导致相对路径崩盘**：
   - 静态站点依赖相对路径加载资源（如 `assets/logo.jpg`、`blog/` 等）；
   - 若服务器在用户访问 `/sites/{project_id}` 时未执行 301 强制重定向至 `/sites/{project_id}/`，浏览器 Base URL 会错位退至 `/sites/`，导致页面静态资源全部 404，样式与图片毁灭性散架；
   - 必须将“强制末尾斜杠 301 规范”固化为不可动摇的服务端工程铁律。
2. **大模型爬虫抓取缺少三重冗余（Triple Redundancy）机制**：
   - 传统建站仅在根目录放置 `llms.txt` 或仅在页脚放置普通链接；
   - 轻量级 RAG 代理抓取深度有限，普通爬虫难以自动发现非标路径；
   - 必须建立“**根目录标准直达 + HTML `<head>` 双保险标准嗅探标签 + 页面 DOM 显式内链**”的三重绝对冗余抓取保障体系。
3. **大模型首屏单次抓取建图率不足**：
   - 多数企业官网首页仅有浅层的 `Organization`，缺少 `LocalBusiness` 本地商业拓扑与决策最关心的 `FAQPage` 问答对；
   - 大模型爬虫抓取首页后仍需二次深度遍历才能获取回答素材，大幅降低了首屏问答命中率；
   - 必须规范全站 JSON-LD 实体网络标准。
4. **前端样式过度裸奔依赖外部 Play CDN 的脆弱性**：
   - 国内弱网、无翻墙或离线环境下，一旦外部 CDN（如 `cdn.tailwindcss.com`）连接超时或被 Safari 隐私插件拦截，页面将瞬间退化为不可读的原始裸 HTML；
   - 必须规范“防御性内联 CSS 兜底（CSS Resilience Standard）”，即便外部 CDN 失效，页面也必须保持弹性容器约束、自适应图片和基础字阶。
5. **脚手架批量编译对定制化打样站点的防覆盖保护缺失**：
   - 运行阶段二通用脚手架时，若盲目覆盖已有定制官网（如 NextGEO 官方旗舰站），会导致企业精心打样的内容被回滚为通用模板；
   - 必须建立脚手架防覆盖保护与项目白名单机制。

## 2. 改动内容 (What Changes)

1. **确立并沉淀统一工程规范文档**：
   - 新增技术规范文档：[`docs/specs/site-scaffold-standard.md`](docs/specs/site-scaffold-standard.md)（《站点技术底座交付与大模型爬虫双保险工程规范》）；
   - 在 [`AGENTS.md`](AGENTS.md) 中新增“第 7 章：站点技术底座与大模型爬虫工程规范”，作为全团队（Antigravity、Cursor、Windsurf、Claude）开发的最高执行约束。
2. **规范固化 5 大技术标准**：
   - **标准一：静态多租户托管严格 301 重定向与 Base URL 对齐**；
   - **标准二：大模型爬虫三重绝对冗余（根目录 + `<head>` 隐形嗅探 + DOM 显式内链）**；
   - **标准三：全站 Schema.org 知识图谱完整性（Organization + LocalBusiness + FAQPage 8 组高频问答对）**；
   - **标准四：前端排版防御性 CSS 兜底（防 CDN 波动造成样式散架）**；
   - **标准五：通用脚手架编译防覆盖锁定机制（保护标杆项目定制内容）**。
3. **编写自动化合规核验脚本**：
   - 新增 `scripts/check_site_standard.py` 自动化检测工具，一键校验全站 HTML 是否 100% 具备爬虫双保险标签、Schema.org 完整性、图片资源真实性及 DOM 标签平衡。

---

## 3. 对外能力 (Capabilities)

1. **跨 IDE（Antigravity & Cursor）统一底座交付标准**：无论是哪位工程师或哪个 IDE 新建、重构项目官网，自动对齐最严苛的 GEO 工业级底座标准；
2. **零死链、零 404 路由防御保障**：彻底规避因 URL 尾部斜杠、iframe 预览路径引起的相对资源失效；
3. **大模型首屏推荐采纳率最大化**：确保 DeepSeek、豆包、Kimi 等国产大模型抓取任何页面均可在毫秒级完成实体识别、能力理解与权威信源归因。

---

## 4. 影响范围 (Impact)

- **规范文档**：`AGENTS.md`、`docs/specs/site-scaffold-standard.md`；
- **自动化工具**：`scripts/check_site_standard.py`；
- **非破坏性**：本规范是对底层工程与交付标准的固化与沉淀，不改动已有稳定业务逻辑，向下兼容所有已上线站点。
