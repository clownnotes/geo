# Proposal: AI原生交钥匙官网重构与阶段二落地折叠指引

## Why (为什么做)
1. **摒弃存量改造泥潭，确立“唯一交钥匙”商业模式**：
   - 中国绝大多数中小企业（SME）的官网往往是凡科、有赞等 SaaS 模板建站，客户手里仅有管理后台账号，根本没有底层源码与服务器运维权限；即便是有独立代码的传统老站，也充斥着老旧技术债，介入修改极易引发扯皮；
   - 本地中小企业找我们做 GEO，核心诉求是“快速见效、省心交付”。因此彻底推翻“帮客户改老代码”的低效路线，确立唯一且极致标准化的交付模式：**不管什么客户，统一交付一套全新专为大模型智能搜索打造的“AI 原生极速官网”（100% 静态纯血源码、秒开、零侵入、交钥匙上线）**。
2. **消除操作黑盒与功能眩晕，注入醒目折叠指引**：
   - 当前工作台功能繁多，向导第二步直接展示冷冰冰的 `/llms.txt`、`JSON-LD` 代码块容易让用户产生“不知道这一页是干嘛的、不知道怎么落地”的困惑；
   - 用户明确提出参考“4090 显卡监控折叠使用说明”的优秀交互范式，需要在第二步顶部构建**模块化折叠说明抽屉**，标明“这页在干嘛”、“核心定位”、“第一步第二步怎么落地”，起到精准提醒与沉浸式引导作用。

## What Changes (改动了什么)
1. **阶段二核心定位升级**：
   - 标题与概念从“阶段二：站点底座技术改造包生成”全面重构升级为 **“阶段二：AI 原生交钥匙官网生成与交付”**；
   - 默认主交付物从“代码补丁片段”升级为 **“100% 完整纯静态现代自适应官网（index.html）”**，并自带 `/llms.txt`、`robots.txt`、`schema.jsonld`。
2. **顶部折叠使用说明看板（Collapsible Instruction Drawer）**：
   - 按照用户提供的参考图样式，设计带有 `📖 使用说明 · 阶段二：AI 原生官网交付 · 怎么落地上线` 与 `点击收起 ▲ / 点击展开 ▼` 的折叠容器；
   - 内置三张横向结构化说明卡片：
     - **🛰️ 这页在干嘛**：白话阐述全量重做一套 AI 官网的核心价值；
     - **🚦 核心定位与模式**：阐述全新交钥匙模式及老域名二级域名挂载的零侵入打法；
     - **📋 操作指引与落地（第一步、第二步）**：清晰说明点击预览、一键打包、部署上线的步骤。
3. **主工作区交互强化**：
   - 增加 **【🖥️ 官网全景预览 (index.html)】** 第一主标签，支持在页面直接查看渲染效果，提供【🌐 新窗口全屏打开官网】与【📦 一键下载整站源码包】；
   - 保留三项底层技术协议代码展示作为专业背书。
4. **后端与流水线闭环**：
   - 升级 `tools/geo/scaffold.py`，流水线自动编译输出普林斯顿标准的高质量 `site/index.html`；
   - 在 `tools/geo/server.py` 增加整站静态预览与 zip 打包导出接口。

## Capabilities (新增或修改的对外能力)
1. **开箱即用 AI 官网生成引擎**：根据项目行业、主理人（老白）、联系电话（13150568888）、微信号（nextdoor8）自动编译出带价格表、FAQ 与 Schema.org 的现代化自适应单页；
2. **可视化折叠使用说明组件**：在 Web 控制台第二步提供可展开/收起的高颜值指导看板，状态持久化缓存；
3. **整站全景预览与极速交付包**：支持一键新窗口在线预览整站，支持一键下载全量静态交付包。

## Impact (受影响的部分)
- `web/index.html`：更新第二步面板 HTML、增加折叠卡片组件、预览交互与脚本逻辑；
- `tools/geo/scaffold.py`：扩展构建函数，自动生成 `outputs/site/index.html`；
- `tools/geo/server.py`：注册 `/api/projects/{id}/site/preview` 及整站打包接口；
- `AGENTS.md` 生产红线：全程锁定本地开发端 `http://127.0.0.1:8088` 严格测试，严禁私自向生产环境发布。
