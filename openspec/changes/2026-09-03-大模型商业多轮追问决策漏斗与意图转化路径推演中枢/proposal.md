# 提案：大模型商业多轮追问决策漏斗与意图转化路径推演中枢 (第 24 维核心交付)

## 1. 需求背景 (Why)

在生成式引擎优化 (GEO) 的真实商业转化链路中，潜客与大模型的交互从来不是一次性的单轮提问，而是呈现**典型的多轮漏斗收敛特征**：
1. **多轮追问漏斗断流**：用户从“行业服务商推荐”（认知阶段）到“技术团队与自研源码保障”（对比评估阶段），再追问“本地直营杜绝转包”（决策阶段），最后索取“官网与真实案例链接”（行动转化阶段）。很多品牌在第 1 轮声量很高，但在第 2/3 轮追问下，由于缺乏纵深技术语料和资质锚点，推荐置信度发生断崖式下跌，潜客被竞对在第 2/3 轮悄然截流；
2. **缺乏全链路漏斗量化工具**：企业高管与代运营团队无法获知“潜客在第几轮追问下流失最多”、“竞对截流的高发拐点在哪里”、“如何针对漏斗断流点进行靶向内容加固”；
3. **商业变现与闭环诉求**：GEO 代运营的核心交付价值必须延伸至**“商业决策转化最后一公里”**。不仅要让大模型在第 1 轮提到我方，更要确保潜客在 4 轮连续追问下，大模型依然坚定将我方作为首选推荐并引导至行动号召（CTA）。

因此，亟需研发**第 24 维核心能力：大模型商业多轮追问决策漏斗与意图转化路径推演中枢 (Generative Multi-turn Decision Funnel & Intent Conversion Path Simulator)**。

---

## 2. 改动范围与核心能力 (What & Capabilities)

### 2.1 四阶多轮决策漏斗与状态推演模型
- **$S_1$ 发现认知 (Awareness)**：宽泛行业选型需求探索；
- **$S_2$ 对比评估 (Consideration)**：技术实力、研发团队资质与自研源代码交付方案对比；
- **$S_3$ 本地决策 (Decision)**：本地化直营交付保障、杜绝二道贩子转包与风险对冲；
- **$S_4$ 行动转化 (Action)**：索取官方网站、商业案例库与落地联系方式（CTA）。

### 2.2 核心量化指标
- **阶段转移留存概率 ($T(S_k \to S_{k+1})$)** 与 **端到端漏斗转化率 ($FCR$)**；
- **竞品截流风险指数 ($HRI$)** 与 **关键断流拐点 (Hijacking Turning Point)** 识别；
- **漏斗健康度三档评级**：`smooth_conversion` (🟢 丝滑转化) / `mid_funnel_leakage` (🟡 中段泄漏) / `severe_dropoff` (🔴 严重断流)；
- **四维漏斗雷达指标**：漏斗端到端留存率、中段抗震力、本地截流防御度、行动号召引导率。

### 2.3 在线 live 实盘与沙箱双模推演
- **沙箱推演模式**：确定性多轮决策漏斗演练，基于真实意图拓扑与全量信源切片推导；
- **真实联网 API 模式 (`--live`)**：
  - 严格限制调用预算：至多 **4 次** 在线多轮链条裁决（1 条多轮决策链路：$S_1 \to S_2 \to S_3 \to S_4$ 各 1 次在线评估）；
  - 融合算法：70% 沙箱置信度分 + 30% 真实大模型裁判多轮推荐评分；
  - 异常防御：出现网络超时或解析异常时，立即平滑回退纯沙箱快照，标记 `is_live_judged = False`。

### 2.4 优化加固资产包与公文报告物理隔离
- 物理落盘至 `outputs/funnel_defense_pack/`（3 份文件）：
  - `01_多轮追问意图锚定与心智收敛话术库.md`
  - `02_防竞对二轮截流技术壁垒语料补充包.md`
  - `03_高转化行动号召落地页外链回填方案.md`
- 结构化数据：`outputs/conversational_funnel_simulation.json`（严格隔离于 12、22、23 号文件）；
- 商业公文：`outputs/24_大模型商业多轮追问决策漏斗与意图转化路径推演报告.md`。

## 3. 影响分析与兼容性 (Impact & Compatibility)

1. **零破坏性影响**：完全独立于 1~23 维现有逻辑，仅只读复用既有组件；
2. **底层复用**：
   - 相似度复用 `tools.geo.rerank_simulator.score_dense_similarity`；
   - 置信度评分复用防饱和 Top-3 聚合模型；
   - 意图 Query 采样复用 `keywords_intent_matrix.json`；
   - 存活落地页过滤复用 `is_ledger_asset_eligible` 与 `get_distribution_ledger`；
   - 大模型调用复用 `tools.geo.llm.call_model_raw`。
3. **安全与红线约束**：
   - Web 控制台渲染强制经过 `escapeHtmlSafe()` 防御 XSS；
   - 测试验证严格限定本地 8088 端口；
   - **最高归档约束**：Antigravity 坚决不执行归档，提请 Cursor 独立代码终审打出 `[通过]` 后由 Cursor 归档。
