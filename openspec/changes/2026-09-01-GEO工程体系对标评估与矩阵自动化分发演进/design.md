## 2. 核心模块与接口设计

### 2.1 分发引擎扩展 (`tools/geo/distribute.py`)
- **知乎专栏格式**：
  - 增强：支持知乎公式、知乎卡片链接语法、代码块格式化，添加作者简介与技术咨询签名。
- **今日头条格式**：
  - 增强：纯文本段落优化、加粗核心对比数字、生成微头条短语料与长文问答对。
- **微信公众号格式**：
  - 增强：生成适合微信后台直接粘贴的富文本内联样式 HTML / 简洁 Markdown。
- **GitHub 开源生态格式**：
  - 增强：带 CI/CD 徽标、Markdown 表格、/llms.txt 链接的完整 `README.md` 与 `docs/` 目录。

### 2.2 反向归因解析器 (`tools/geo/monitor.py`)
- **输入**：大模型 Live Probing 返回的原始答案字符串（含 Markdown 超链接或 `[1]` 引用标号）。
- **解析逻辑**：
  1. 使用正则匹配所有引用外链：`r'https?://[^\s)\]]+'`；
  2. 提取根域名（如 `zhihu.com`, `toutiao.com`, `github.com`, 客户官网）；
  3. 统计各信源在大模型答案中出现的频次占比（Source Authority Score）。
- **输出**：在 `05_企业AI可见度与声量追踪周报.md` 中增加【权威信源渗透分布表】。

## 3. 行业对标核心结论与量化指标

| 对标维度 | 传统线下 GEO 代运营 (手工作坊) | 本工程化 GEO 平台 (工业化母机) |
| :--- | :--- | :--- |
| **理论模型** | 沿用老套关键词密度与人工发帖外链 | 普林斯顿 9 因子 + RAG 切片 + 实体消歧 |
| **技术底座能力** | ❌ 0 代码能力，无法修改官网底座 | ✅ 自动生成 `/llms.txt` + `JSON-LD` + `robots.txt` |
| **生产耗时** | 3~7 天（依赖人工文案编写） | **< 30 秒**（全套标准化白皮书与对比表） |
| **边际交付成本** | 随客户增加线性增加人工成本 | **边际成本趋近于 0**（单机可承载数百客户） |
| **大模型采纳率** | 缺乏结构化与数据，容易被降权 | 结构化表格与量化数据，采纳率提升 +30%~+41% |
| **分发操作** | 纯人工手工编辑与排版 | **一键生成各平台专属格式，即拷即发** |

## 4. 安全与性能考量
- 所有的富文本与 Markdown 处理保持在 Python 原生库与轻量级转换内，保持 0 第三方臃肿依赖；
- 分发包生成严格限制在客户工作区 `projects/<client_id>/outputs/` 内，杜绝路径穿越；
- 保持公私数据隔离，管理端接口继续受 Token 鉴权保护。
