# enterprise-onboarding Specification

## Purpose
规范 GEO 企业客户极简建档流程、输入校验规则、雪花 ID 唯一主键生成、后厂配置目录幂等初始化、独立物理字段持久化以及建档成功后直接跳转企业工作台的端到端行为契约。

## Requirements

### Requirement: 极简建档输入校验与核心母盘约束
系统建档表单 SHALL 仅强制要求录入 3 项核心业务信息（日常品牌简称、主打核心品类、15 至 80 字的一句话业务与优势描述），并支持 6 项选填资产（公司工商全称复用 name、主打客群、官网域名复用 domain、官方电话/微信、期望问题库、已知竞品）；任何不符合字数要求或缺少必填项的请求 MUST 被拒绝。

#### Scenario: 提交合法完整的 3 项必填字段成功建档
- **WHEN** 客户端提交包含合法品牌简称、核心品类及 15 至 80 字业务优势的建档请求
- **THEN** 系统校验通过，成功创建企业档案记录并返回 HTTP 201 状态码与新建的企业详情

#### Scenario: 缺少必填字段或一句话母盘字数不合规被拦截
- **WHEN** 客户端提交缺少核心品类，或一句话优势少于 15 字或超过 80 字的建档请求
- **THEN** 系统校验失败并拒绝创建，返回 HTTP 400 状态码与明确参数错误原因

### Requirement: 剔除冗余字段与关闭代号入参
系统建档界面与建档请求结构体 SHALL NOT 包含项目唯一英文代号入参、服务辐射范围卡片、归属合作方下拉框及默认二级域名生成复选框；代号由系统基于雪花 ID 自动分配，若企业无官网，系统 MUST 保持域名为空，SHALL NOT 默认分配伪二级域名。

#### Scenario: 前端建档界面不展示冗余输入组件
- **WHEN** 管理员打开新建企业档案弹窗
- **THEN** 表单中不展示项目唯一代号输入框、服务辐射范围卡片、归属合作方选择器及默认分配二级域名的复选框

#### Scenario: 未填官网域名时保持空态不生成假域名
- **WHEN** 管理员在未填写官网域名的情况下提交建档
- **THEN** 数据库中保存的域名保持为空字符串或 NULL，系统不生成也不绑定形如 {代号}.baicl.cc 的默认二级域名

### Requirement: 雪花 ID 唯一主键与绝对产物路径派生
系统 MUST 使用全局分布式雪花 ID 作为企业档案的唯一标识与前店业务路由参数；在持久化新档案时，系统 SHALL 自动将雪花 ID 字符串写入 code 列，并将静态产物路径 output_dir 初始化为与 Nginx 规则一致的绝对路径，保障后厂磁盘目录与 Nginx 规则兼容。

#### Scenario: 新建档案自动生成雪花主键与绝对产物路径
- **WHEN** 后端受理新建企业档案请求
- **THEN** 系统生成唯一的分布式雪花 ID 主键，自动将 code 初始化为该雪花 ID 字符串，并将 output_dir 设为绝对路径后安全落盘

#### Scenario: 存量老项目通过雪花 ID 路由且原有代号不受破坏
- **WHEN** 业务接口接收存量老项目的雪花 ID 查询请求
- **THEN** 系统精准定位存量记录，其原有 code 与 outputs 磁盘路径映射保持原样不变

### Requirement: 后厂目录骨架与配置档案幂等同步
当 Go 后端向 GEO 后厂 Worker 提交异步计算任务时，系统 SHALL 在任务参数中附带企业档案属性；后厂 Worker 在执行任务前 MUST 检查 projects/{project_id}/ 目录骨架与 project.yaml 是否存在，若不存在则基于传入参数幂等生成（将问题库切分为 keywords 列表，将竞品切分为 competitors 列表，写入 business_one_liner 与 area_served），防止下游引擎因配置缺失或类型错位报错。

#### Scenario: 首次调用后厂任务自动生成 project.yaml 与目录
- **WHEN** 小毛驴 Go 后端向后厂提交新创建企业的首个异步计算任务
- **THEN** 后厂引擎在执行计算前自动创建 projects/{project_id}/ 目录与 outputs/ 子目录，并写入规范的 project.yaml 配置文件，keywords 与 competitors 严格组织为 YAML 列表

#### Scenario: 重复调用后厂任务保持幂等安全
- **WHEN** 小毛驴 Go 后端多次向同一企业提交不同的异步计算任务
- **THEN** 后厂引擎复用既有目录与配置，不破坏已有产物文件且计算任务顺利执行

### Requirement: 档案创建成功直达企业工作台
在管理端任意入口（包括快捷建档弹窗与档案列表页）成功创建企业档案后，系统 MUST 自动关闭弹窗，将当前全局企业上下文切换为该新建企业的雪花 ID，并将界面无缝导航至该企业的工作台干活面板。

#### Scenario: 快捷新建企业成功后直接跳转工作台
- **WHEN** 管理员在快捷新建弹窗中点击确认创建且接口返回成功
- **THEN** 弹窗自动关闭，系统自动选中新企业，切换至工作台面板，并在浏览器地址栏 query 参数中携带新建企业的雪花 ID

#### Scenario: 档案列表页新建成功后直接跳转工作台
- **WHEN** 管理员在档案管理列表页完成新建企业操作
- **THEN** 页面自动导航至企业工作台并将当前作业上下文设置为该新企业，用户无需手动在列表查找再点击进入
