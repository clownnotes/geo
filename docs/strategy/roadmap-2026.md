> **战略基调**：**拒绝为了功能堆砌而开发，坚决砍掉低效重复与自嗨逻辑，聚焦核心商业价值。**

## 一、战略调整与价值过滤准则（三大铁律）

在完成了前期 1~26 维度的技术底座搭建与推演中枢后，系统已具备深厚的底层算法与工程框架。面对下一阶段的演进，我们确立**“三大价值过滤铁律”**作为后续一切需求立项与代码开发的最高准绳：

```
                           ┌────────────────────────────────────────────────────────┐
                           │               GEO 战略研发价值过滤三铁律                │
                           └───────────────────────────┬────────────────────────────┘
                                                       │
         ┌─────────────────────────────────────────────┼─────────────────────────────────────────────┐
         │                                             │                                             │
         ▼                                             ▼                                             ▼
【铁律 1: 搜索质量真实提升】                 【铁律 2: SOP 生产大幅提效】                  【铁律 3: 商业交付更具代差】
• 必须直接提高大模型爬虫抓取解析率           • 必须解决一线代运营真实“脏活累活”            • 必须让非技术高管/客户秒懂震撼
• 必须显著提升 RAG 向量检索召回率           • 杜绝多平台繁琐复制与格式错乱               • 摆脱低端自媒体外包形象，拉开技术代差
```

### 1. 铁律一：对搜索质量提升有立竿见影的效果
* **坚决不做**：脱离大模型实际检索机理的微小数学自嗨扰动、无训练语料支撑的虚构评分；
* **优先要做**：直接影响主流 AI 爬虫（字节 Bytespider、百度 Baiduspider 等）Clean Markdown 解析完整度、深度对齐普林斯顿 9 因子、提升 RAG 向量召回与重排挤占率的硬核技术机制。

### 2. 铁律二：对团队日常代运营 SOP 工作流有巨大提效
* **坚决不做**：逻辑重复、流程断节、需要人工来回跨工具复制粘贴的冗余交互；
* **优先要做**：打通从“内容生成 ➔ 渠道排版 ➔ 结构化元数据注入 ➔ 一键复制发布 ➔ 分发台账探活”的全链条极速通道，让代运营人员“10 秒内完成一篇符合大模型高收录标准的图文排版与发布准备”。

### 3. 铁律三：对商业客户交付与续约提供专业支撑
* **坚决不做**：把复杂的工程师调试控制台和晦涩终端日志直接丢给不懂技术的甲方老板；
* **优先要做**：打造高管专属的免密/提取码只读汇报大屏与结案中枢，用数据量化呈现“心智渗透率（MPI）、年化等效广告价值、竞对截流破局战果”，展现传统 SEO 公司无法比拟的专业代差，直接驱动客户痛快打款与季度续约。

## 六、研发执行约束与纪律保障

1. **规范驱动不可动摇**：每一维度的开发必须严格遵循 OpenSpec 规范（`./opsx propose` ➔ 跨 IDE 审查 ➔ 逐项 apply ➔ 测试秒绿 ➔ 跨 IDE 终审归档）；
2. **测试驱动保驾护航**：全库单测须保持绿（当前约 **258** 组，随功能增减以 `unittest discover` 为准）；新增功能必须配套完备的单元测试；
3. **严格遵守生产红线**：本地测试统一锁定在 `http://127.0.0.1:8088`，未经用户明确授权，绝不擅自向生产机（`mini` / `geo.baicl.cc`）推代码或重启生产进程；
4. **代码双远端同步**：阶段性验证通过后，保持 `git push origin main` 与 `git push github main` 的双端完全一致性。
