# 答题卡 vs 母盘（名词尺子）

> **用途**：交付选词与建库时，团队口头别混用。  
> **一句话**：母盘 = 真相本；答题卡 = 拿去对外答题的一张张稿。

---

## 1. 对照

| | **母盘** | **答题卡** |
| :--- | :--- | :--- |
| 是什么 | 企业已确认的事实与口径总库 | 针对**某一个（组）关键词/问句**写好的对外答案文 |
| 像什么 | 厨房里的食材清单 + 配方真源 | 端上桌的一道菜（可复制到头条/知乎） |
| 我们仓里大致对应 | `raw_materials/ledger/facts.*`、知识库、`llms.txt` 实体口径 | 阶段三语料切片、阶段四定稿（如 `toutiao_pack`） |
| 谁维护 | 建档/提纯时写入；错了先改母盘 | 按词生产、IDE 定稿、写回后再发 |
| 能不能直接当发稿 | 一般不直接整库粘贴发平台 | 可以（定稿后） |

---

## 2. 「把什么关键词覆盖掉」指什么

- 选中一批要抢的问句/词 → 每条词至少对应 **1 张答题卡**（可一文盖近义问法，但台账要记清主词）。  
- **覆盖** = 这个词在目标平台上已有我方定稿答案文在线，而不是只在母盘里有一句简介。  
- 母盘不「覆盖关键词」；母盘只保证答题卡写的时候**有据可查、不编数**。

---

## 3. 硬规则

1. 答题卡里的数字/边界，必须能在母盘（facts）找到来源；母盘没有的数字不许上答题卡。  
2. 发稿与监测按**答题卡（词 × 链接）**追，不按「整库发过了」糊弄。  
3. 母盘更新后，已发答题卡要标记是否需改稿（与战略欠账「词×定稿×链接」台账衔接）。
