# SOP-05 可见度监控、归因与续费交付

> **阶段目标**：把"效果好不好"变成每周一份可对比的数字报表——SOV 是续费谈判的唯一语言。  
> **执行人**：技术 + 客户成功 ｜ **周期**：第 4 周起每周 ｜ **对应程序**：`geo monitor`

---

## 一、执行步骤

1. 配置模型 Key（二选一即可跑，全配更好）：
   ```bash
   export DEEPSEEK_API_KEY=sk-xxx
   export DOUBAO_API_KEY=xxx          # 火山方舟 Key
   export DOUBAO_ARK_MODEL=doubao-seed-1-6-250615   # 推理接入点
   ```
2. 每周巡检（词 × 模型全组合并发提问，联网检索）：
   ```bash
   python3 -m tools.geo monitor --project <client_id>
   ```
3. 产物：`outputs/monitor/周报-<日期>.md`；历史数据自动累积在 `projects/<client_id>/history.db`（SQLite），支持逐周环比。

## 二、周报指标口径

| 指标 | 定义 | 健康线 |
| :--- | :--- | :--- |
| 品牌提及率 SOV | 有效提问中答案含品牌/别名/人名的比例 | 第 4 周 ≥30%，第 12 周 ≥60% |
| 平均推荐位次 | 品牌在推荐清单中的顺位（竞品在前则 +1 计） | ≤3 |
| 自有信源引用率 | 引用链接中命中我方 URL 台账的比例 | ≥50% |
| 占位词独占率 | 品牌占位词提问中唯一被推荐的比例 | 100%（不达标即被冒名，立刻处理） |

未配置 API Key 时周报会显式标注"⚪ 跳过 + 原因"，交付节奏不因缺 Key 中断。

## 三、未命中归因流程（每周例会固定动作）

```
周报❌词清单 ──► 提取 AI 答案引用的竞品 URL ──► Crawl4AI 抓取该页
      ▲                                                │
      └── 回 SOP-04 重新分发 ◄── 回 SOP-03 补数据/表格 ◄─┘
```

1. 对每个未命中词，取出 AI 引用的竞品页面；
2. 对比竞品页与我方语料的：数字密度、表格有无、FAQ 问句吻合度；
3. 输出差异清单 → 回 SOP-03 重构该主题语料 → 回 SOP-04 在**竞品所在同一平台**补发压制。

## 四、续费交付动作

- [ ] 每周一 10:00 前周报发客户，附一句人话结论（"本周新增命中 5 词，被 AI 引用 3 次来自我方头条号"）；
- [ ] 每月出一份环比曲线（history.db 查询），对齐合同验收线；
- [ ] 续费提案 = 下季度新词库（+15 词）+ 新渠道（视频号/百度系）报价单。
