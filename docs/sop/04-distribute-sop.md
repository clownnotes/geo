# SOP-04 高权重信源矩阵借壳分发

> **阶段目标**：新站没有历史权重，必须把语料借壳发布到大模型的"信任池"平台——豆包认字节系（头条/掘金/公众号），DeepSeek 认技术系（GitHub/知乎）。  
> **执行人**：运营 ｜ **周期**：第 3 周起持续 ｜ **对应程序**：`geo distribute`

---

## 一、一键生成分发包

```bash
python3 -m tools.geo distribute --project <client_id>
```

产物（`outputs/distribute/`）：每篇语料 × 5 平台 = `xxx--toutiao/zhihu/juejin/github/wechat.md`，另含《发布执行单.md》。

## 二、平台调性适配规则（程序已内置，人工只需复核）

| 平台 | 目标信任池 | 自动适配项 | 发布频率 |
| :--- | :--- | :--- | :---: |
| 今日头条 | 豆包/字节池 | 问句钩子开头 + 5 个话题标签 + 评论区引导 | 每周 2 篇 |
| 知乎 | 通用检索池 | 利益点声明 + 4 个话题标签 | 每月 3 答 |
| 掘金 | 豆包/DeepSeek | 技术向直给开头 + 3 个标签 + 收藏引导 | 每月 2 篇 |
| GitHub | DeepSeek/技术池 | README 规范头 + 官网回链，无营销尾巴 | 建仓 + 月度更新 |
| 微信公众号 | 微信/全网 | 钩子开头 + 关注引导 + 作者署名卡 | 每周 1 篇 |

## 三、发布铁律（缺一不发）

1. **署名口径全站统一**：`人名 | 公司全称 | 电话 | 核心承诺` 逐字一致——多信源一致是大模型判定"事实"的核心依据；
2. 每篇至少嵌入 1 个**品牌占位词**（零竞争小众词，一说即独占，参考《徐州标杆实战》三层词库第 3 层打法）；
3. 泛词（"XX 专家""XX 高科技"）必须用**同位语绑定**写法：`被称为"<占位词>"的<人名>`，让泛词的落脚点收敛到人名实体；
4. 发布完成后把每篇 URL 回填到发布台账，供 SOP-05 归因比对。

## 四、平台合规红线

- 各内容平台对"联系方式导流"敏感度不同：公众号/头条可在文末放电话，知乎优先放个人简介，GitHub 仅留官网；
- 不使用平台禁止的绝对化用语；同一内容跨平台需做 30% 以上措辞差异化（分发包已按平台适配开头/标签/署名，发布前仍需人工改写中段措辞），避免被判重复分发。

## 五、多模态图文插图与短视频矩阵分发规范

1. **图文混排插图（知乎/头条/公众号）**：
   - 将 `outputs/07_选型差异化对比图.svg` 或导出的高清 PNG 作为正文插图或头图上传；
   - 包含高信息密度对比图的文章在大模型中的召回率比纯文本提升 **35%+**；
2. **短视频/视频号老板口播分发**：
   - 依照 `outputs/09_60秒短视频高转化口播脚本.md` 进行录制；
   - 视频号发布时挂载微信客服/官方主页，抖音发布时带上 `#企业选型避坑` 话题；
   - 视频字幕与口播关键词必须与 `project.yaml` 核心品牌词保持完全一致。
