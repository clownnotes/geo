# SOP-04 矩阵分发（首次交付 80 分）

> **阶段目标**：把「能核对的答案」发到大模型常抓的池子（头条→豆包，知乎→DeepSeek）。  
> **执行人**：运营 ｜ **写作尺子**：[`docs/specs/answer-source-writing.md`](../specs/answer-source-writing.md)  
> **分工**：管理台 = **路牌**（下一步做什么）；**IDE = 工地**（改稿与写回）。  
> **关键认知**：生成 = 草稿；定稿在 IDE；满意后用**写回口令**落盘；勾选「可以发」只是放行。

---

## 一、首次交付要达到什么（80 分）

- [ ] 今日头条 **1 篇定稿答案文**已发布，URL 填回台账且「链接还在」  
- [ ] 走过：**生成草稿 → 说明书 → IDE 改稿 → 写回口令落盘 → 勾选可以发 → 复制发布**  
- [ ] 署名口径与 `project.yaml` / 官网一致  
- [ ] 发布账号已标明：客户号 / 我方号  

**不要求首次做完**：微信周更、GitHub、百科、短视频、五平台全绿。  
**不要求**管理台内嵌长文编辑器，也**不要求**管理台大粘贴框填稿。

---

## 二、管理台第四页：从上到下的区块顺序（硬约束）

| 顺序 | 区块 | 运营动作 |
| :---: | :--- | :--- |
| 1 | 生成草稿 | 点「生成草稿」；状态显示「仅草稿」 |
| 2 | 说明书（段 A） | 读主问句、用途、模具、可写事实 |
| 3 | 怎么定稿（段 B） | 「复制给 IDE 改写」→ IDE 里改到满意 →「复制写回口令」贴回 IDE 落盘 |
| 4 | 发布前确认（段 C） | 选账号 → 勾「定稿已写好，可以发」→「复制富文本去头条」 |
| 5 | 回填链接 | 贴 URL，「保存并检查」只看链接还在不在（主要抓 404） |

**禁止**：段 C（可以发）出现在段 B（IDE 定稿）之前。

段 B 固定旁注：

> 本页只指路。定稿在 IDE 写；满意后点「复制写回口令」让 AI 写入规定文件；再回来勾「可以发」。勾选不会改文章。

```bash
# 命令行仍可生成草稿包
python3 -m tools.geo distribute --project <client_id>
```

## 三、按钮语义

| 按钮 | 语义 | 禁止 |
| :--- | :--- | :--- |
| 生成草稿 | 只产半成品 | 「一键发布包 / 已就绪可发」 |
| 复制给 IDE 改写 | 带走说明书+草稿（去 IDE 开工） | 当成发稿剪贴板；藏进「更多」当唯一入口 |
| 复制写回口令 | 告诉 IDE：满意正文写入哪条路径（落盘留档） | 当成发稿；要求写完必须立刻落盘（可先聊后落） |
| 检查写回 | 看磁盘上文件在不在、标题/字数/开头预览 | 当成「勾选就等于已写回」 |
| 定稿已写好，可以发 | 人工放行确认 | 当成「一键定稿」或自动改写 |
| 复制富文本去头条/知乎 | 定稿后发平台 | 未勾选可发时无弱化、无确认 |
| 小毛驴审定稿（可选） | 审发布同源文件 | 审另一份无关 Markdown |

## 四、账号铁律（首次）

1. 优先客户号发**答题文**  
2. 我方号仅过渡；禁止一号批量发多家公司简介  
3. 电话全文建议 ≤ 2 次，放文末  

---

## 五、回填与链接检查

只检查网址还在不在（主要抓 404），不爬正文，也不代表大模型已抓到。

```bash
python3 -m tools.geo record <client_id> --channel toutiao --url "https://www.toutiao.com/article/真实ID/"
python3 -m tools.geo verify-dist <client_id>
```

## 六、后续维护（另案 · 战略欠账）

周更、多号池、五池拉满、视频、自动质检产品化、定稿只读预览 → 单独变更。

### 欠账：关键词 × 定稿 × 链接 运营台账（未立项）

- **要做**：按「主问句/关键词」管理已发答案文：定稿路径、发布 URL、账号、探活与是否需改稿；与现有渠道级 `dist_ledger` 衔接或升级。  
- **为什么**：首次只发少数篇；日常要按监测补文/改文。只有渠道链接、没有「这篇答的是哪个词」，后面找不到人、交不了班。  
- **现在不做**：首次 80 分用渠道回填即可；细账等「一文一链」变多或阶段五要词级复测时再立项。  
- **战略登记处**：[`docs/strategy/roadmap-2026.md`](../strategy/roadmap-2026.md) §四点五 欠账 A。

## 七、验收勾选

- [ ] 页面顺序：说明书 → IDE 定稿区 → 可以发/复制发布（段 C 不在段 B 前）  
- [ ] 「可以发」文案标明：只是确认，不是写作工具  
- [ ] 段 B 能复制「写回口令」，口令含写回路径  
- [ ] IDE 改写包字段齐全；写回与发布同源  
- [ ] 可发确认后发出，头条 URL 填回且链接还在  
- [ ] 账号类型已记录
