## 🌐 GEO SOP 网站规划路线（下一步计划）

* **技术选型**：推荐采用 **VitePress** 或 **Astro / Next.js** 搭建轻量高性能文档与工具站。
* **核心模块**：
  1. **战略与原理区**：通俗讲解 GEO 逻辑与大模型推荐机制；
  2. **客户交付 SOP 互动区**：按 Stage 1 ~ Stage 5 提供可勾选的任务清单与进度看板；
  3. **模版中心**：一键复制 `llms.txt`、`JSON-LD`、行业白皮书、对比表格模版；
  4. **AI 体检与巡检工具区**：在线/命令行自动化检测网站是否被 AI 友好解析。
