## 🖥️ 快速上手与本地运行

### 1. 运行本地开发控制台（默认端口 8088）
```bash
# 启动可视化 Web 运营大盘与交互式管理端
./geo serve --port 8088

# 访问浏览器控制台
open http://127.0.0.1:8088
```

### 2. 核心 CLI 工具链调用示例
```bash
# 1. 售前全网诊断
./geo audit --target "https://example.com" --project "my_project"

# 2. 普林斯顿 9 因子重构与全案量化质检
./geo rewrite --project "my_project"
./geo princeton --project "my_project"

# 3. 商业意图三级矩阵与竞对差距逆向推演
./geo intent --project "my_project" --level3
./geo competitor --project "my_project"

# 4. 商业心智 (MPI) 与因果归因量化
./geo mindshare --project "my_project"
./geo causal --project "my_project"

# 5. 商业博弈护城河推演
./geo moat --project "my_project"

# 6. 生成商业交付验收单与结案资产归档
./geo acceptance --project "my_project"
./geo certificate --project "my_project"
```

### 3. 本地全套自动化单测运行

python3 -m unittest discover -s tests -p "test_*.py"

## 🛡️ 协同纪律与生产防护红线（AGENTS.md）

1. **生产发布触发协议（最高优先级约束）**：
   - **严禁私自/自动向生产服务器（`mini` / `geo.baicl.cc`）部署或重启生产进程**；
   - 开发与审查阶段的所有代码与功能**一律仅在本地开发端（http://127.0.0.1:8088）测试与验证**；
   - **只有当用户明确指示推生产（如“部署到生产”、“推到线上网站”）时**，方可执行生产发布。
2. **Git 协同推送规范**：
   - 阶段性测试通过后，Git 仓库必须正常执行提交并推送到远端（`git push origin main` 与 `git push github main`），确保多端代码同步。
